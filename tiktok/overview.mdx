## Overview

The ScrapeBadger **TikTok API** turns `tiktok.com` into a clean JSON feed:
user **profiles** and their videos, **video** detail with comments, replies,
related posts and subtitle **transcripts**, **hashtag** and **sound** pages,
global **search**, **trending** feeds, and TikTok's EU **Ad Library**
(Commercial Content Library) — including single-ad detail with the full
targeting/impression breakdown and advertiser lookup by name.

<Info>
  All endpoints are `GET`, live under `https://scrapebadger.com/v1/tiktok/*`,
  and authenticate with the `X-API-Key` header. Credits are charged per request
  (see the tables below) and reported on the `X-Credits-Used` response header.
</Info>

<Note>
  No TikTok account, developer app, or access token is required. Content
  endpoints accept a `region` (ISO 3166-1 alpha-2, default `US`); the Ad Library
  is EU-only and defaults to `DE`.
</Note>

## Users

| Endpoint | Description | Credits |
| -------- | ----------- | ------- |
| `GET /users/{username}` | Full profile (stats, bio, verification) | 5 |
| `GET /users/{username}/videos` | A user's posted videos (cursor-paginated) | 8 |
| `GET /users/{username}/followers` | Public followers (cursor-paginated) | 10 |
| `GET /users/{username}/following` | Public following (cursor-paginated) | 10 |
| `GET /users/{username}/liked` | Public liked videos (cursor-paginated) | 10 |
| `GET /users/{username}/reposts` | A user's reposts | 8 |

<Note>
  Public followers, following and liked lists are available without a TikTok
  account. Private profiles and hidden liked lists return HTTP 403.
</Note>

## TikTok Shop (e-commerce)

TikTok Shop's storefront — categories, paginated search, store catalogues,
product detail and paginated reviews. `region` picks
the market: `US` (everything), `GB` and `ID` (categories, products and product
detail). See [TikTok Shop](/api-reference/endpoint/tiktok/shop).

| Endpoint | Description | Credits |
| -------- | ----------- | ------- |
| `GET /shop/categories` | Root category list | 5 |
| `GET /shop/categories/{category_id}` | Subcategories + top products of a category | 5 |
| `GET /shop/search` | Keyword search, 30 per page with offset pagination | 5 |
| `GET /shop/stores/{seller_id}` | Store stats + cursor-paginated catalogue | 5 |
| `GET /shop/products/{product_id}` | Full product detail: SKUs, prices, first reviews, shop | 8 |
| `GET /shop/products/{product_id}/reviews` | Paginated reviews with rating breakdown | 5 |

## Ad Library (EU-DSA transparency)

TikTok's **Commercial Content Library** — ad-transparency data for the EU. Use
an EU `region` (default `DE`).

| Endpoint | Description | Credits |
| -------- | ----------- | ------- |
| `GET /ads/search` | Search ads by keyword or advertiser id | 5 |
| `GET /ads/advertisers` | Look up advertiser business ids by name | 5 |
| `GET /ads/{ad_id}` | Single-ad detail: advertiser + full targeting/impression breakdown | 8 |

<Tip>
  Chain the Ad Library endpoints: `ads/advertisers?query=Nike` → take an
  advertiser `id` → `ads/search?advertiser_id=<id>` to list all their ads → take
  an ad `id` → `ads/{ad_id}` for the per-region age/gender impression breakdown.
</Tip>

## Response conventions

<ResponseField name="datetimes" type="dual-format">
  Every datetime ships in **both** forms: `*_utc` (Unix integer, for math and
  sorting) and `*_at` (ISO 8601 UTC string, for display).
</ResponseField>
<ResponseField name="unknown fields" type="forward-compatible">
  Responses may add fields over time; SDK models ignore unknown fields so your
  integration never breaks on an addition.
</ResponseField>

## SDKs

Every endpoint is available in all ScrapeBadger SDKs. For example, in Python and
Node the Ad Library lives under `client.tiktok.ads`:

<CodeGroup>

```python Python
from scrapebadger import ScrapeBadger

async with ScrapeBadger(api_key="YOUR_API_KEY") as client:
    advertisers = await client.tiktok.ads.search_advertisers("nike", region="DE")
    ads = await client.tiktok.ads.search(advertiser_id=advertisers.advertisers[0].id)
    detail = await client.tiktok.ads.get_detail(ads.ads[0].id, region="DE")
    print(detail.targeting.target_audience_size)
```

```javascript Node.js
import { ScrapeBadger } from "scrapebadger";

const client = new ScrapeBadger({ apiKey: "YOUR_API_KEY" });
const advertisers = await client.tiktok.ads.searchAdvertisers({ query: "nike", region: "DE" });
const ads = await client.tiktok.ads.search({ advertiser_id: advertisers.advertisers[0].id });
const detail = await client.tiktok.ads.getDetail(ads.ads[0].id, { region: "DE" });
console.log(detail.targeting.target_audience_size);
```

</CodeGroup>

## Guest access and pagination

Public content uses guest web and mobile providers; you do not need a TikTok
account. Public followers/following and reposts support pagination. Liked lists
are available only when the profile exposes them publicly. Hidden/private data
returns 403, temporarily unavailable data returns 503, and an expired continuation
cursor returns 410. Pass cursors unchanged with the same resource and region;
guest continuation state lasts up to 15 minutes and expires when its guest session
is replaced or the service restarts. Social lists reflect the subset TikTok exposes
to that guest; they are not a guaranteed complete follower export.

Web and mobile responses share the documented models, but optional native-only
fields may be null. A populated metadata response does not guarantee that a media
URL is downloadable: TikTok may reject even a fresh CDN URL with 403. Media links
are upstream references, not a guaranteed download service. Mobile hashtag/song recommendations are not
historical Creative Center rankings: omit `period`; only US is currently verified.
