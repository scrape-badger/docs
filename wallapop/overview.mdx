## Scraper API for Wallapop

Search **second-hand listings** with Wallapop's own filters, pull **full listing detail** (description, attributes, photos, views, and favorites), and look up **seller profiles**, their live listings, and the **reviews** they received across Wallapop's **3 markets** — Spain, Italy, and Portugal. Prices are in EUR.

## Markets

A Wallapop market picks two things: the **default search location** and the **language** of category names, filter labels, and attribute text.

| Market | Country | Default search location | Language | Currency |
|--------|---------|-------------------------|----------|----------|
| :es: `es` | Spain | Madrid (40.4168, -3.7038) | `es-ES` | EUR |
| :it: `it` | Italy | Rome (41.9028, 12.4964) | `it-IT` | EUR |
| :portugal: `pt` | Portugal | Lisbon (38.7223, -9.1393) | `pt-PT` | EUR |

Wallapop searches by location, not by domain. Pass `latitude` and `longitude` to [search](/api-reference/endpoint/wallapop/search-items) around any point. Those coordinates override the market's default location, and the country searched follows them: coordinates in Barcelona return Spanish listings even with `market=it`. Each search response reports the country Wallapop searched in as `country_code`.

<Tip>
  If no `market` is specified, it defaults to `es`. Use [`/v1/wallapop/markets`](/api-reference/endpoint/wallapop/list-markets) to get the list, with default coordinates, programmatically.
</Tip>

## Quick Start

<CodeGroup>

```bash cURL
curl "https://scrapebadger.com/v1/wallapop/search?query=iphone+14&market=es&max_price=400" \
  -H "X-API-Key: YOUR_API_KEY"
```

```python Python
import requests

res = requests.get(
    "https://scrapebadger.com/v1/wallapop/search",
    headers={"X-API-Key": "YOUR_API_KEY"},
    params={"query": "iphone 14", "market": "es", "max_price": 400},
)
data = res.json()

for item in data["items"]:
    print(item["price"], item["title"], item["url"])
```

```javascript Node.js
const res = await fetch(
  "https://scrapebadger.com/v1/wallapop/search?" +
    new URLSearchParams({ query: "iphone 14", market: "es", max_price: "400" }),
  { headers: { "X-API-Key": process.env.SCRAPEBADGER_API_KEY } },
);
const data = await res.json();

for (const item of data.items) {
  console.log(item.price, item.title, item.url);
}
```

```bash CLI
scrapebadger wallapop search "iphone 14" --market es --max-price 400
```

## Pagination

Search, user listings, and user reviews return up to **40 results per page** and a `next_page` cursor.

1. Make the first request with your parameters.
2. To get the next page, send `next_page` back **on its own**, with the same `market`. The cursor carries the original query and filters, so any other search parameters are ignored.
3. When `next_page` is `null`, there are no more results.

```python
import requests

params = {"query": "bicicleta", "market": "es"}
items = []
while True:
    data = requests.get(
        "https://scrapebadger.com/v1/wallapop/search",
        headers={"X-API-Key": "YOUR_API_KEY"},
        params=params,
    ).json()
    items += data["items"]
    if not data["next_page"] or len(items) >= 200:
        break
    params = {"next_page": data["next_page"], "market": "es"}
```
