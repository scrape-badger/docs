Every SDK below exposes the same API surface — 29 scrapers, 400+ operations —
because they are all generated from the ScrapeBadger OpenAPI specification.
A new endpoint lands in every language at the same time.

Authentication is identical everywhere: pass your API key and the SDK sends it
as the `x-api-key` header.

## Example

<CodeGroup>

```python Python
import requests

response = requests.get(
    'https://scrapebadger.com/v1/twitter/users/elonmusk/by_username',
    headers={'x-api-key': 'YOUR_API_KEY'}
)
print(response.json())
```

```go Go
package main

import (
    "context"
    "fmt"

    scrapebadger "github.com/scrape-badger/scrapebadger-go"
)

func main() {
    cfg := scrapebadger.NewConfiguration()
    cfg.AddDefaultHeader("x-api-key", "YOUR_API_KEY")
    client := scrapebadger.NewAPIClient(cfg)

    user, _, err := client.TwitterAPI.
        TwitterGetUserByUsername(context.Background(), "elonmusk").Execute()
    if err != nil {
        panic(err)
    }
    fmt.Println(user)
}
```

</CodeGroup>

## Bypassing the cache

An identical request within 60 seconds returns the cached response at 0 credits.
To get a fresh response, send the `Cache-Control: no-cache` header. It is off by
default. See [Bypassing the cache](/credits-and-pricing#bypassing-the-cache).

The Python and Node.js SDKs (0.77.0 or later) have an option for it:

<CodeGroup>

```python Python
from scrapebadger import ScrapeBadger

# Every request from this client
client = ScrapeBadger(api_key="YOUR_API_KEY", no_cache=True)

# One call only
client = ScrapeBadger(api_key="YOUR_API_KEY")
await client.with_options(no_cache=True).perplexity.ask_perplexity_a_question_post(
    payload={"prompt": "best crm for startups"}
)
```

```javascript Node.js
import { ScrapeBadger } from "scrapebadger";

// Every request from this client
const fresh = new ScrapeBadger({ apiKey: "YOUR_API_KEY", noCache: true });

// One call only
const client = new ScrapeBadger({ apiKey: "YOUR_API_KEY" });
await client
  .withOptions({ noCache: true })
  .perplexity.askPerplexityAQuestionPost({ prompt: "best crm for startups" });
```

</CodeGroup>

In the other SDKs, set `Cache-Control: no-cache` as a default header on the API
client, the same way you set `x-api-key`. For example, in Dart:
`sb.dio.options.headers['Cache-Control'] = 'no-cache';`

<Note>
The generated SDK repositories are replaced wholesale on every API change —
never send pull requests to them. Issues and feature requests belong on the
[roadmap](https://github.com/scrape-badger/roadmap).
</Note>
