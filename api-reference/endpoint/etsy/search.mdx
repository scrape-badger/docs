Search listings.

**Credits:** 10 per successful request. Failed requests and empty result sets are not charged.

## Authentication

<ParamField header="X-API-Key" type="string" required>Your ScrapeBadger API key.</ParamField>

## Parameters

<ParamField query="query" type="string" required>
Query. Minimum length: 1. Maximum length: 250.
</ParamField>

<ParamField query="page" type="integer" default="1">
Page. Minimum: 1. Maximum: 250.
</ParamField>

<ParamField query="country" type="string" default="US">
Country.
</ParamField>

<ParamField query="currency" type="string" default="USD">
Currency.
</ParamField>

<ParamField query="language" type="string" default="en-US">
Language.
</ParamField>

<ParamField query="sort" type="string" default="most_relevant">
Sort. Allowed values: `most_relevant`, `date_desc`, `price_asc`, `price_desc`.
</ParamField>

<ParamField query="min_price" type="number">
Min price. Minimum: 0.
</ParamField>

<ParamField query="max_price" type="number">
Max price. Minimum: 0.
</ParamField>

```bash

  --header 'X-API-Key: YOUR_API_KEY' \
  --data-urlencode 'query=ceramic mug'
```
