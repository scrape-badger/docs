Get shop reviews.

**Credits:** 20 per successful request. Failed requests and empty result sets are not charged.

## Authentication

<ParamField header="X-API-Key" type="string" required>Your ScrapeBadger API key.</ParamField>

## Parameters

<ParamField path="shop_name" type="string" required>
Shop name.
</ParamField>

<ParamField query="page" type="integer" default="1">
Page. Minimum: 1. Maximum: 10000.
</ParamField>

<ParamField query="country" type="string" default="US">
Country.
</ParamField>

<ParamField query="currency" type="string" default="USD">
Currency.
</ParamField>

<ParamField query="language" type="string" default="en-US">
Language.
</ParamField>
