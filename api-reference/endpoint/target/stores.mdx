Find nearby stores.

**Credits:** 5 per successful request. Failed requests and empty result sets are not charged.

## Authentication

<ParamField header="X-API-Key" type="string" required>Your ScrapeBadger API key.</ParamField>

## Parameters

<ParamField query="zip_code" type="string" required>
Zip code.
</ParamField>

<ParamField query="limit" type="integer" default="10">
Limit. Minimum: 1. Maximum: 20.
</ParamField>

## Example

```bash
curl --get 'https://scrapebadger.com/v1/target/stores' \
  --header 'X-API-Key: YOUR_API_KEY' \
  --data-urlencode 'zip_code=55403' \
  --data-urlencode 'limit=10'
```
