title: "Search products"
api: "GET https://scrapebadger.com/v1/target/search"
description: "Search products."
---

Search products.

**Credits:** 5 per successful request. Failed requests and empty result sets are not charged.

## Authentication

<ParamField header="X-API-Key" type="string" required>Your ScrapeBadger API key.</ParamField>

## Parameters

<ParamField query="query" type="string" required>
Query. Minimum length: 1.
</ParamField>

<ParamField query="page" type="integer" default="1">
Page. Minimum: 1. Maximum: 50.
</ParamField>

<ParamField query="page_size" type="integer" default="24">
Page size. Minimum: 1. Maximum: 24.
</ParamField>

<ParamField query="store_id" type="string" default="1375">
Store id.
</ParamField>

<ParamField query="zip_code" type="string" default="55403">
Zip code.
</ParamField>

<ParamField query="sort" type="string" default="relevance">
Sort. Allowed values: `relevance`, `PriceLow`, `PriceHigh`, `RatingHigh`, `bestselling`, `newest`.
</ParamField>

## Example

```bash

  --header 'X-API-Key: YOUR_API_KEY' \
  --data-urlencode 'query=laptop' \
  --data-urlencode 'page=1' \
  --data-urlencode 'page_size=24' \
  --data-urlencode 'store_id=1375' \
  --data-urlencode 'zip_code=55403' \
  --data-urlencode 'sort=relevance'
```
