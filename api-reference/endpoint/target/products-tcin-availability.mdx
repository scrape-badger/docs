Get product availability.

**Credits:** 10 per successful request. Failed requests and empty result sets are not charged.

## Authentication

<ParamField header="X-API-Key" type="string" required>Your ScrapeBadger API key.</ParamField>

## Parameters

<ParamField path="tcin" type="string" required>
Tcin.
</ParamField>

<ParamField query="zip_code" type="string" required>
Zip code.
</ParamField>

<ParamField query="limit" type="integer" default="10">
Limit. Minimum: 1. Maximum: 20.
</ParamField>
