List supported markets.

**Credits:** 0 per successful request. Failed requests and empty result sets are not charged.

## Authentication

<ParamField header="X-API-Key" type="string" required>Your ScrapeBadger API key.</ParamField>

## Response

```json
{
  "markets": [
    {
      "code": "us",
      "name": "United States",
      "currency": "USD"
    }
  ]
}
```

## Example

```bash
curl --get 'https://scrapebadger.com/v1/target/markets' \
  --header 'X-API-Key: YOUR_API_KEY'
```
