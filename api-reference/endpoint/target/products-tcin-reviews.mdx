---
title: "Get product reviews"
api: "GET https://scrapebadger.com/v1/target/products/{tcin}/reviews"
description: "Get product reviews."
---

Get product reviews.

**Credits:** 5 per successful request. Failed requests and empty result sets are not charged.

## Authentication

<ParamField header="X-API-Key" type="string" required>Your ScrapeBadger API key.</ParamField>

## Parameters

<ParamField path="tcin" type="string" required>
Tcin.
</ParamField>

<ParamField query="page" type="integer" default="1">
Page. Minimum: 1.
</ParamField>

<ParamField query="page_size" type="integer" default="10">
Page size. Minimum: 1. Maximum: 50.
</ParamField>

<ParamField query="sort" type="string" default="most_recent">
Sort. Allowed values: `most_recent`, `most_helpful`, `highest_rated`, `lowest_rated`.
</ParamField>
