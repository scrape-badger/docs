Autocomplete ASOS searches.

**Credits:** 3 per successful request. Failed requests and empty result sets are not charged.

## Authentication

<ParamField header="X-API-Key" type="string" required>Your ScrapeBadger API key.</ParamField>

## Parameters

<ParamField query="query" type="string" required>
Query. Minimum length: 1. Maximum length: 200.
</ParamField>

<ParamField query="market" type="string" default="uk">

</ParamField>

</ParamField>

<ParamField query="country" type="string">

</ParamField>

Currency.
</ParamField>

Language.
</ParamField>

## Example

