The common Facebook Marketplace **location slugs**. Not exhaustive — any city
slug Facebook accepts works — these are the high-traffic ones surfaced for
convenience.

**Credits:** 0 (free)

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Response

<ResponseField name="locations" type="Location[]">
  Each `Location` has `slug` (the value you pass as a `location` parameter) and
  `name` (the human-readable city).
</ResponseField>
<ResponseField name="count" type="integer">Number of locations returned.</ResponseField>

## Example

<CodeGroup>

```bash cURL
curl "https://scrapebadger.com/v1/facebook/marketplace/locations" \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const res = await fetch(
  "https://scrapebadger.com/v1/facebook/marketplace/locations",
  { headers: { "X-API-Key": process.env.SCRAPEBADGER_API_KEY } },
);
const data = await res.json();
```

```python Python
import requests

res = requests.get(
    "https://scrapebadger.com/v1/facebook/marketplace/locations",
    headers={"X-API-Key": "YOUR_API_KEY"},
)
data = res.json()
```
