The common Facebook Marketplace **location slugs**, surfaced for convenience.

Not exhaustive, and **not guessable**: only places Facebook itself has minted a
slug for resolve. `london` and `newcastleupontyne` do; `durham` and `sunderland`
do not, and
[`/marketplace/search`](/api-reference/endpoint/facebook/marketplace-search)
returns a `400 invalid_location` for those rather than silently searching
Facebook's San Francisco default.

To cover a town that has no slug, search a nearby location that does have one
and read `city_page_id` off the listings — those numeric Facebook place ids are
valid `location` values. See
[Location targeting](/api-reference/endpoint/facebook/marketplace-search#location-targeting).

**Credits:** 0 (free)

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Response

<ResponseField name="locations" type="Location[]">
  Each `Location` has `slug` (the value you pass as a `location` parameter) and
  `name` (the human-readable city).
</ResponseField>
<ResponseField name="count" type="integer">Number of locations returned.</ResponseField>
