The Facebook Marketplace top-level **category slugs**, the vocabulary behind
the `category_id` field on a listing.

**Credits:** 0 (free)

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Response

<ResponseField name="categories" type="Category[]">
  Each `Category` has `slug` and `name` (the human-readable label).
</ResponseField>
<ResponseField name="count" type="integer">Number of categories returned.</ResponseField>

## Example

<CodeGroup>

```bash cURL
curl "https://scrapebadger.com/v1/facebook/marketplace/categories" \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const res = await fetch(
  "https://scrapebadger.com/v1/facebook/marketplace/categories",
  { headers: { "X-API-Key": process.env.SCRAPEBADGER_API_KEY } },
);
const data = await res.json();
```

```python Python
import requests

res = requests.get(
    "https://scrapebadger.com/v1/facebook/marketplace/categories",
    headers={"X-API-Key": "YOUR_API_KEY"},
)
data = res.json()
```
