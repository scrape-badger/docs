---
title: "Search Listings"
api: "GET https://scrapebadger.com/v1/wallapop/search"
description: "Search Wallapop second-hand listings in Spain, Italy, or Portugal with Wallapop's own filters — price, condition, brand, model, colour, distance, listing age, shipping, and car filters."
---

Search Wallapop listings, **40 per page**, with the same filters the Wallapop app offers. Send a `query`, a `category_id`, or both.

**Credits:** 5 per page. Empty results are not charged.

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Query Parameters

<ParamField query="query" type="string">
  Search text, e.g. `iphone 14`, `bicicleta montaña`. Required unless you pass `category_id`; requests with neither return `422`.
</ParamField>

<ParamField query="market" type="string" default="es">
  `es` (Spain), `it` (Italy), or `pt` (Portugal). Sets the default search location (Madrid, Rome, or Lisbon) and the language of category and attribute text. Any other value returns `422`. See [`/v1/wallapop/markets`](/api-reference/endpoint/wallapop/list-markets).
</ParamField>

<ParamField query="latitude" type="number">
  Search centre latitude, `-90` to `90`. Defaults to the market's capital. The country searched follows the coordinates, not the market.
</ParamField>

<ParamField query="longitude" type="number">
  Search centre longitude, `-180` to `180`. Defaults to the market's capital.
</ParamField>

<ParamField query="distance_km" type="integer">
  Radius around the search centre in kilometres, `1` to `500`. Omit to search without a radius limit.
</ParamField>

<ParamField query="category_id" type="integer">
  Category id from [`/v1/wallapop/categories`](/api-reference/endpoint/wallapop/list-categories), e.g. `24200` (Technology & electronics) or `100` (Cars). Required unless you pass `query`.
</ParamField>

<ParamField query="min_price" type="number">
  Minimum price in EUR, `0` or more.
</ParamField>

<ParamField query="max_price" type="number">
  Maximum price in EUR, `0` or more.
</ParamField>

<ParamField query="condition" type="string">
  Comma-separated conditions: `un_opened`, `in_box`, `new`, `as_good_as_new`, `good`, `fair`, `has_given_it_all`. Example: `new,as_good_as_new`.
</ParamField>

<ParamField query="brand" type="string">
  Brand option id, e.g. `Apple`. Get valid ids from [`/v1/wallapop/filters/brand/options`](/api-reference/endpoint/wallapop/list-filter-options) for your category or query.
</ParamField>

<ParamField query="model" type="string">
  Model option id, e.g. `iPhone 14`. Get valid ids from [`/v1/wallapop/filters/model/options`](/api-reference/endpoint/wallapop/list-filter-options).
</ParamField>

<ParamField query="color" type="string">
  Colour option id, e.g. `black`. Valid ids are listed under the `color` filter in [`/v1/wallapop/filters`](/api-reference/endpoint/wallapop/list-filters).
</ParamField>

<ParamField query="time_filter" type="string">
  Only listings published within: `today`, `lastWeek`, or `lastMonth`.
</ParamField>

<ParamField query="shippable" type="boolean" default="false">
  `true` returns only listings that can be shipped.
</ParamField>

<ParamField query="has_warranty" type="boolean" default="false">
  `true` returns only listings with a warranty.
</ParamField>

<ParamField query="refurbished" type="boolean" default="false">
  `true` returns only refurbished listings.
</ParamField>

<ParamField query="order_by" type="string" default="most_relevance">
  Sort order: `most_relevance`, `newest`, `closest`, `price_low_to_high`, or `price_high_to_low`.
</ParamField>

<ParamField query="next_page" type="string">
  Cursor from the previous response's `next_page`. Send it on its own (with the same `market`): the cursor carries the original query and filters, and all other search parameters are ignored.
</ParamField>

### Car filters

These filters apply when you search cars with `category_id=100`.

<ParamField query="min_year" type="integer">
  Earliest model year, e.g. `2015`.
</ParamField>

<ParamField query="max_year" type="integer">
  Latest model year.
</ParamField>

<ParamField query="min_km" type="integer">
  Minimum mileage in km, `0` or more.
</ParamField>

<ParamField query="max_km" type="integer">
  Maximum mileage in km, `0` or more.
</ParamField>

<ParamField query="gearbox" type="string">
  `manual` or `automatic`.
</ParamField>

<ParamField query="min_horsepower" type="integer">
  Minimum engine power in hp, `0` or more.
</ParamField>

<ParamField query="max_horsepower" type="integer">
  Maximum engine power in hp, `0` or more.
</ParamField>

<Note>
  For car searches, `brand` and `model` take the car make and model option ids from [`/v1/wallapop/filters/brand/options?category_id=100`](/api-reference/endpoint/wallapop/list-filter-options) and `/v1/wallapop/filters/model/options?category_id=100`.
</Note>

<Info>
  There is no sold-listings search: Wallapop search only returns live listings. To see what a seller has sold, read their [reviews](/api-reference/endpoint/wallapop/get-user-reviews) — reviews with `type: "sell"` name the listing they sold.
</Info>

## Example

<CodeGroup>

```bash cURL
curl "https://scrapebadger.com/v1/wallapop/search?query=iphone&market=es&shippable=true" \
  -H "X-API-Key: YOUR_API_KEY"
```

```python Python
import requests

res = requests.get(
    "https://scrapebadger.com/v1/wallapop/search",
    headers={"X-API-Key": "YOUR_API_KEY"},
    params={"query": "iphone", "market": "es", "shippable": "true"},
)
data = res.json()
```

```javascript Node.js
const res = await fetch(
  "https://scrapebadger.com/v1/wallapop/search?" +
    new URLSearchParams({ query: "iphone", market: "es", shippable: "true" }),
  { headers: { "X-API-Key": process.env.SCRAPEBADGER_API_KEY } },
);
const data = await res.json();
```

```bash CLI
scrapebadger wallapop search "iphone" --market es --shippable
```

</CodeGroup>

Car search — manual cars from 2015 on with under 100,000 km, closest to Madrid first:

```bash
curl "https://scrapebadger.com/v1/wallapop/search?category_id=100&min_year=2015&max_km=100000&gearbox=manual&order_by=closest" \
  -H "X-API-Key: YOUR_API_KEY"
```

## Errors

| Status | Cause |
|--------|-------|
| `422` | Neither `query` nor `category_id` was sent, a value is out of range, or `market` is not `es`, `it`, or `pt`. |
| `502` | Wallapop did not answer after retries. Not charged — retry the request. |

<Note>
  Each search request costs **8 credits**. Pages with no results and failed requests are not charged.
</Note>
