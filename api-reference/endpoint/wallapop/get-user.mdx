---
title: "Get User"
api: "GET https://scrapebadger.com/v1/wallapop/users/{user_id}"
description: "Wallapop seller profile — rating, reviews, sales and purchase counters, response rate, verifications, location, and registration date."
---

A Wallapop user's public profile with their rating, sales and purchase counters, response rate, and verifications.

**Credits:** 5

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Path Parameters

<ParamField path="user_id" type="string" required>
  The user, as an **id** — `dqjwdd53wwzo` (the `user_id` field of any listing) — or a **profile slug** — `alexc-25115753` (the last part of a `wallapop.com/user/...` URL). The id is fastest.
</ParamField>

## Query Parameters

<ParamField query="market" type="string" default="es">
  `es`, `it`, or `pt`. Sets the host of the returned `url`. See [`/v1/wallapop/markets`](/api-reference/endpoint/wallapop/list-markets).
</ParamField>

</ResponseField>
<ResponseField name="location" type="Location | null">

  <Expandable title="Location">
    <ResponseField name="latitude" type="number | null" />

<ResponseField name="rating_average" type="number | null">Average review rating, `0`–`5`.</ResponseField>

    <ResponseField name="picture" type="boolean | null">Profile picture set.</ResponseField>
    <ResponseField name="location" type="boolean | null">Location set.</ResponseField>
    <ResponseField name="birthday" type="boolean | null">Birthday set.</ResponseField>
    <ResponseField name="kyc" type="boolean | null">Identity (KYC) verified.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="slug" type="string | null">Profile slug, e.g. `alexc-25115753`.</ResponseField>
<ResponseField name="url" type="string | null">Full profile URL on wallapop.com.</ResponseField>
<ResponseField name="registered_utc" type="number | null">Registration time, Unix seconds.</ResponseField>
<ResponseField name="registered_at" type="string | null">Registration time, ISO 8601 UTC.</ResponseField>

<Tip>
  If the counters or verifications are temporarily unavailable, the profile is still returned with those fields set to `null`.
</Tip>

## Errors

| Status | Cause |
|--------|-------|
| `404` | The user does not exist. Not charged. |
| `422` | `market` is not `es`, `it`, or `pt`. |
| `502` | Wallapop did not answer after retries. Not charged — retry the request. |

<Note>
  Each profile lookup costs **5 credits**. Failed requests are not charged.
</Note>
