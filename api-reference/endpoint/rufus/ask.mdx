---
title: "Ask Amazon Rufus"
api: "POST https://scrapebadger.com/v1/rufus/ask"
description: "Ask Alexa for Shopping (Rufus) and get the complete answer and recommended product cards as structured JSON, with optional ASIN product context."
---

Ask a shopping question and receive the real Rufus answer after its streamed response finishes. `GET` accepts query parameters; `POST` accepts the same fields in a JSON body.

**Credits:** 50 per successful answer

<Warning>
  Allow up to **100 seconds**. Empty answers, `softlanding_error`, truncated streams, authentication failures, and upstream errors return non-2xx responses and are not billed.
</Warning>

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Parameters

<ParamField query="prompt" type="string" required>
  The shopping question to ask. Maximum **4,000 characters**. Include all context needed because every request starts an independent conversation.
</ParamField>

<ParamField query="asin" type="string">
  Optional 10-character product ASIN, matching `^[A-Z0-9]{10}$`. Rufus opens that product page before answering, making the question product-aware.
</ParamField>

## Response

<ResponseField name="answer" type="string">The complete answer text after all JSON Patch events have been applied.</ResponseField>
<ResponseField name="products" type="RufusProduct[]">Ordered product recommendations. Empty when the answer contains no product cards.</ResponseField>
<ResponseField name="thread_id" type="string | null">Amazon's server-side conversation identifier, returned for tracing. Not a multi-turn input.</ResponseField>
<ResponseField name="model" type="string">Always `rufus`.</ResponseField>
<ResponseField name="domain" type="string">Always `com`.</ResponseField>
<ResponseField name="asin" type="string | null">The product context you supplied, or `null` for a general shopping question.</ResponseField>
<ResponseField name="stream_terminated" type="boolean">Whether Amazon closed the response stream cleanly.</ResponseField>
<ResponseField name="elapsed_ms" type="integer">End-to-end request time in milliseconds.</ResponseField>

<Expandable title="RufusProduct">
  <ResponseField name="asin" type="string">Product ASIN.</ResponseField>
  <ResponseField name="title" type="string | null">Product title or image alt text.</ResponseField>
  <ResponseField name="url" type="string">Canonical `https://www.amazon.com/dp/{asin}` URL.</ResponseField>
  <ResponseField name="price" type="string | null">Displayed price, including currency symbol.</ResponseField>
  <ResponseField name="rating" type="number | null">Rating out of five.</ResponseField>
  <ResponseField name="rating_count" type="integer | null">Number of ratings.</ResponseField>
  <ResponseField name="badge" type="string | null">Merchandising badge, such as `Best Seller` or `Amazon's Choice`.</ResponseField>
  <ResponseField name="image_url" type="string | null">Product image URL.</ResponseField>
  <ResponseField name="rank" type="integer">One-based position in the answer.</ResponseField>
</Expandable>

## Example

<CodeGroup>

```bash cURL
curl "https://scrapebadger.com/v1/rufus/ask?asin=B09M7WWTFP&prompt=What%20are%20the%20main%20tradeoffs%20of%20this%20product%3F" \
  -H "X-API-Key: YOUR_API_KEY" \
  --max-time 100
```

```javascript Node.js
const res = await fetch("https://scrapebadger.com/v1/rufus/ask", {
  method: "POST",
  headers: {
    "X-API-Key": process.env.SCRAPEBADGER_API_KEY,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    prompt: "What are the main tradeoffs of this product?",
    asin: "B09M7WWTFP",
  }),
  signal: AbortSignal.timeout(100_000),
});
const data = await res.json();
console.log(data.answer);
console.log(data.products);
```

```python Python
import requests

res = requests.post(
    "https://scrapebadger.com/v1/rufus/ask",
    headers={"X-API-Key": "YOUR_API_KEY"},
    json={
        "prompt": "What are the main tradeoffs of this product?",
        "asin": "B09M7WWTFP",
    },
    timeout=100,
)
data = res.json()
print(data["answer"])
print(data["products"])
```

## Errors

Errors use `{"detail":{"code":"...","message":"..."}}`.

| Code | HTTP | Meaning |
| ---- | ---- | ------- |
| `pool_disabled`, `pool_exhausted` | 503 | No authenticated account is currently available. Retry later. |
| `authentication_required` | 503 | Amazon requested fresh authentication and the affected session was rotated. |
| `blocked` | 422 | Amazon served an anti-bot page. Not billed. |
| `answer_timeout`, `stream_truncated`, `softlanding_error` | 502 | The response did not complete successfully. Not billed. |
| `empty_answer` | 502 | The stream ended without usable answer text. Not billed. |
| `composer_not_found`, `new_chat_unavailable`, `upstream_error` | 502 | The upstream page or answer failed. Not billed. |
