---
title: "List Amazon Rufus Models"
api: "GET https://scrapebadger.com/v1/rufus/models"
description: "List the Amazon shopping assistant surface exposed by the Rufus API."
---

Return the assistant surface available through this API. The catalogue is read-only; `/ask` does not accept a model-selection parameter.

**Credits:** 1

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Response

<ResponseField name="models" type="Model[]">
  The available Amazon shopping assistant surface.

  <Expandable title="Model">
    <ResponseField name="id" type="string">Stable identifier, `rufus`.</ResponseField>
    <ResponseField name="name" type="string">Display name, `Alexa for Shopping (Rufus)`.</ResponseField>
    <ResponseField name="description" type="string">Description of the shopping assistant.</ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>

```bash cURL
curl "https://scrapebadger.com/v1/rufus/models" \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const res = await fetch("https://scrapebadger.com/v1/rufus/models", {
  headers: { "X-API-Key": process.env.SCRAPEBADGER_API_KEY },
});
console.log((await res.json()).models);
```

```python Python
import requests

res = requests.get(
    "https://scrapebadger.com/v1/rufus/models",
    headers={"X-API-Key": "YOUR_API_KEY"},
)
print(res.json()["models"])
```
