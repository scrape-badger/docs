---
title: "Brand Visibility"
api: "GET https://scrapebadger.com/v1/grok/brand-visibility"
description: "Measure brand mentions, share of voice, position, competitors, and citation rank in a real Grok answer."
---

Ask Grok a buyer-intent prompt and receive the full answer plus deterministic brand-visibility analysis. Accepts `GET` and `POST`.

**Credits:** 25

## Authorization

<ParamField header="X-API-Key" type="string" required>Your ScrapeBadger API key.</ParamField>

## Parameters

<ParamField query="prompt" type="string" required>Buyer or category prompt, maximum 4,000 characters.</ParamField>
<ParamField query="brand" type="string" required>Brand name to measure.</ParamField>
<ParamField query="competitors" type="string[]">Competitor names. Repeat the query parameter on `GET`, or use a JSON array on `POST`.</ParamField>
<ParamField query="brand_domain" type="string">Domain used to calculate `citation_rank`.</ParamField>
<ParamField query="mode" type="string" default="auto">`auto`, `fast`, or `expert`.</ParamField>
<ParamField query="web_search" type="string" default="force">`auto`, `force`, or `off`. Defaults to `force` for grounded visibility analysis.</ParamField>

## Response

<ResponseField name="mentioned" type="boolean">Whether the brand appears in the answer.</ResponseField>
<ResponseField name="mention_count" type="integer">Number of brand mentions.</ResponseField>
<ResponseField name="share_of_voice" type="number">Brand mentions divided by all brand and competitor mentions, from 0 to 1.</ResponseField>
<ResponseField name="position" type="integer | null">Character offset of the first mention.</ResponseField>
<ResponseField name="citation_rank" type="integer | null">One-based rank of `brand_domain` in `source_domains`.</ResponseField>
<ResponseField name="competitors" type="Competitor[]">Each competitor with `brand`, `mentioned`, and `mention_count`.</ResponseField>
<ResponseField name="answer" type="string">The full Grok answer.</ResponseField>
<ResponseField name="citations" type="Citation[]">Inline citations, in the same shape as `/ask`.</ResponseField>
<ResponseField name="search_results" type="SearchResult[]">Web sources used by Grok.</ResponseField>
<ResponseField name="x_search_results" type="XPost[]">X post references used by Grok.</ResponseField>

## Example

```bash cURL
curl -G "https://scrapebadger.com/v1/grok/brand-visibility" \
  -H "X-API-Key: YOUR_API_KEY" \
  --data-urlencode "prompt=What are the best web scraping APIs?" \
  --data-urlencode "brand=ScrapeBadger" \
  --data-urlencode "competitors=Bright Data" \
  --data-urlencode "competitors=Apify" \
  --data-urlencode "brand_domain=scrapebadger.com" \
  --max-time 90
```
