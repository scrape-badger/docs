---
title: "Get Conversation"
api: "GET https://scrapebadger.com/v1/grok/conversations/{conversation_id}"
description: "Fetch chronological user and assistant messages from an existing Grok conversation."
---

Retrieve normalized messages from a Grok conversation created by `/ask`.

**Credits:** 3

## Authorization

<ParamField header="X-API-Key" type="string" required>Your ScrapeBadger API key.</ParamField>

## Path Parameters

<ParamField path="conversation_id" type="string" required>The complete opaque ID returned by `/ask`, for example `187055:2121372254449864788`.</ParamField>

## Response

<ResponseField name="conversation_id" type="string">The requested conversation ID.</ResponseField>
<ResponseField name="messages" type="Message[]">Chronological messages with `id`, `role`, `content`, `file_attachments`, `created_utc` (Unix seconds), and `created_at` (ISO-8601 UTC).</ResponseField>
<ResponseField name="count" type="integer">Number of returned messages.</ResponseField>
<ResponseField name="next_cursor" type="string | null">Upstream pagination cursor.</ResponseField>
