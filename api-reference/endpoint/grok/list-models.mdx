---
title: "List Models"
api: "GET https://scrapebadger.com/v1/grok/models"
description: "List the auto, fast, and expert assistant modes available for Grok answers."
---

Return the assistant modes accepted by `/ask` and `/brand-visibility` through their `mode` parameter.

**Credits:** 1

## Authorization

<ParamField header="X-API-Key" type="string" required>Your ScrapeBadger API key.</ParamField>

## Response

<ResponseField name="models" type="Model[]">Modes with `id`, `name`, and `description`.</ResponseField>

```json Response
{
  "models": [
    {"id": "auto", "name": "Auto", "description": "Grok chooses the answering mode."},
    {"id": "fast", "name": "Fast", "description": "Low-latency answers with optional web and X search."},
    {"id": "expert", "name": "Expert", "description": "Deeper reasoning for difficult prompts."}
  ]
}
```
