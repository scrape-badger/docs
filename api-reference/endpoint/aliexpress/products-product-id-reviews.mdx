description: "Get product reviews."
---

Get product reviews.

**Credits:** 5 per successful request. Failed requests and empty result sets are not charged.

## Authentication

<ParamField header="X-API-Key" type="string" required>Your ScrapeBadger API key.</ParamField>

## Parameters

<ParamField path="product_id" type="string" required>
Product id.
</ParamField>

<ParamField query="page" type="integer" default="1">
Page. Minimum: 1. Maximum: 10000.
</ParamField>

<ParamField query="page_size" type="integer" default="10">
Page size. Minimum: 1. Maximum: 50.
</ParamField>

<ParamField query="sort" type="string" default="complex_default">
Sort. Allowed values: `complex_default`, `latest_sort`.
</ParamField>
