Get store products.

**Credits:** 10 per successful request. Failed requests and empty result sets are not charged.

## Authentication

<ParamField header="X-API-Key" type="string" required>Your ScrapeBadger API key.</ParamField>

## Parameters

<ParamField path="store_id" type="string" required>
Store id.
</ParamField>

<ParamField query="page" type="integer" default="1">
Page. Minimum: 1. Maximum: 1000.
</ParamField>

<ParamField query="page_size" type="integer" default="24">
Page size. Minimum: 1. Maximum: 60.
</ParamField>

<ParamField query="country" type="string" default="US">
Country.
</ParamField>

<ParamField query="currency" type="string" default="USD">
Currency.
</ParamField>

<ParamField query="language" type="string" default="en">
Language.
</ParamField>

<ParamField query="query" type="string" default="">
Query. Maximum length: 250.
</ParamField>

<ParamField query="sort" type="string" default="bestmatch_sort">
Sort. Allowed values: `bestmatch_sort`, `price_asc`, `price_desc`, `orders_desc`.
</ParamField>
