---
title: "User Posts"
api: "GET https://scrapebadger.com/v1/instagram/users/{username}/posts"
description: "Paginated posts for a user, wrapped in the standard list envelope."
---

Page through a public user's `posts`.

**Credits:** 8 per request

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Path Parameters

<ParamField path="username" type="string" required>
  Instagram handle without the `@`.
</ParamField>

## Query Parameters

<ParamField query="amount" type="integer" default="12">
  Page size — how many media items to return this page.
</ParamField>

<ParamField query="cursor" type="string">
  Opaque next-page token from a previous response's `next_cursor`. Omit for the
  first page.
</ParamField>

## Response

<ResponseField name="items" type="Media[]">
  Media cards — see the [Get Media](/api-reference/endpoint/instagram/get-media)
  field reference (`pk`, `id`, `code`, `taken_at`/`_utc`, `media_type`,
  `product_type`, `caption_text`, `like_count`, `comment_count`, `play_count`,
  `thumbnail_url`, `video_url`, `url`, `user`, `resources`, …).
</ResponseField>
<ResponseField name="count" type="integer">Items in this page.</ResponseField>
<ResponseField name="next_cursor" type="string">Pass back as `cursor` for the next page (null when exhausted).</ResponseField>
<ResponseField name="has_more" type="boolean">Whether more pages remain.</ResponseField>

## Example

<CodeGroup>

```bash cURL
curl "https://scrapebadger.com/v1/instagram/users/instagram/posts?amount=12" \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
let cursor, all = [];
do {
  const res = await fetch(
    "https://scrapebadger.com/v1/instagram/users/instagram/posts?" +
      new URLSearchParams({ amount: "12", ...(cursor && { cursor }) }),
    { headers: { "X-API-Key": process.env.SCRAPEBADGER_API_KEY } },
  );
  const page = await res.json();
  all.push(...page.items);
  cursor = page.has_more ? page.next_cursor : null;
} while (cursor);
```

```python Python
import requests

cursor, items = None, []
while True:
    res = requests.get(
        "https://scrapebadger.com/v1/instagram/users/instagram/posts",
        headers={"X-API-Key": "YOUR_API_KEY"},
        params={"amount": 12, **({"cursor": cursor} if cursor else {})},
    )
    page = res.json()
    items += page["items"]
    if not page["has_more"]:
        break
    cursor = page["next_cursor"]
```
