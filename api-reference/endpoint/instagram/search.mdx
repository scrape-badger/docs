title: "Search"

---

Search Instagram by keyword. Every search endpoint takes `query`.

**Credits:** 8 (`users`, `places`, `top`, `reels`, `music`) · 3 (`hashtags`, `autocomplete`)

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Query Parameters

<ParamField query="query" type="string" required>
  The search term.
</ParamField>

<ParamField query="amount" type="integer" default="20">
  **`users` only** — how many accounts to return (1–100).
</ParamField>

<ParamField query="lat" type="number">
  **`places` only, optional** — latitude to bias the ranking toward. Without
  `lat`/`lng` the ranking is global.
</ParamField>

<ParamField query="lng" type="number">
  **`places` only, optional** — longitude, paired with `lat`.
</ParamField>

<ParamField query="cursor" type="string">
  **`top` and `reels` only** — opaque next-page token.
</ParamField>

## Paths

- `GET /v1/instagram/search/users` — matching accounts (`UserShort[]`). **8 credits.**
- `GET /v1/instagram/search/hashtags` — matching hashtags (`Hashtag[]`). **3 credits.**
- `GET /v1/instagram/search/places` — matching places. **8 credits.**
- `GET /v1/instagram/search/top` — blended top results (users, hashtags, places). **8 credits.**
- `GET /v1/instagram/search/reels` — reels matching the keyword. **8 credits.**
- `GET /v1/instagram/search/music` — matching audio tracks. **8 credits.**
- `GET /v1/instagram/search/autocomplete` — keyword typeahead suggestions. **3 credits.**

## Response

<ResponseField name="items" type="object[]">
  `users`, `hashtags`, `places` and `music` return typed results wrapped in
  `{ items, count, next_cursor, has_more }`. `top`, `reels` and
  `autocomplete` return Instagram's blended payload.
</ResponseField>

## Example

<CodeGroup>

```bash cURL
curl "https://scrapebadger.com/v1/instagram/search/hashtags?query=travel" \
  -H "X-API-Key: YOUR_API_KEY"

curl "https://scrapebadger.com/v1/instagram/search/top?query=nasa" \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const res = await fetch(
  "https://scrapebadger.com/v1/instagram/search/hashtags?" +
    new URLSearchParams({ query: "travel" }),
  { headers: { "X-API-Key": process.env.SCRAPEBADGER_API_KEY } },
);
const { items } = await res.json();
```

```python Python
import requests

res = requests.get(
    "https://scrapebadger.com/v1/instagram/search/hashtags",
    headers={"X-API-Key": "YOUR_API_KEY"},
    params={"query": "travel"},
)
items = res.json()["items"]
```
