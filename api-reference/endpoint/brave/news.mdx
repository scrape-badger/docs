---
title: "News search"
openapi: "GET /v1/brave/news"
description: "News search from native Brave Search."
---

Returns the initial native news batch. There is no pagination or freshness parameter. Relative source ages remain display strings; observation time is not publication time.

**Credits:** 7. Confirmed empty results and failed requests are unbilled.

`query` must be nonblank and no longer than 2,048 characters. Country and UI-language
codes come from the [locale reference](/api-reference/endpoint/brave/locales).
Safe-search accepts `off`, `moderate`, or `strict` (default).

## Errors

Invalid or unsupported parameters return `422`; unavailable source content returns
an error instead of a billable empty result. A key without the `brave` scope returns `403`.

See the [overview](/brave/overview) for pagination, fields and authentication.
