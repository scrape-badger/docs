---
title: "Shopping Keyword Periods"
api: "GET https://scrapebadger.com/v1/naver/shopping/keyword-periods"
description: "The list of available periods for the Naver Shopping keyword ranking, for a category and age bracket."
---

List the **available periods** for the Naver Shopping keyword ranking — the weeks or months you can request from [`/shopping/keywords`](/api-reference/endpoint/naver/shopping-keywords) for a given category and age bracket. The complete period list is returned in one response.

**Credits:** 5

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Query Parameters

<ParamField query="category_id" type="string" default="A">
  `A`, or an 8-digit category id.
</ParamField>

<ParamField query="age_type" type="string" default="ALL">
  Age bracket, e.g. `ALL`, `MEN_20`.
</ParamField>

<ParamField query="sort_type" type="string" default="KEYWORD_NEW">
  Fixed at `KEYWORD_NEW`.
</ParamField>

<ParamField query="period_type" type="string" default="WEEKLY">
  `WEEKLY` or `MONTHLY`.
</ParamField>

## Response

<ResponseField name="category_id" type="string" />
<ResponseField name="age_type" type="string" />
<ResponseField name="sort_type" type="string" />
<ResponseField name="period_type" type="string" />
<ResponseField name="result_count" type="integer" />
<ResponseField name="periods" type="Period[]">
  Available periods.

  <Expandable title="Period">
    <ResponseField name="ymd" type="string">Period start date, `YYYYMMDD`.</ResponseField>
    <ResponseField name="ended_at" type="string">Period end date.</ResponseField>
    <ResponseField name="month" type="integer" />
    <ResponseField name="week" type="integer" />
    <ResponseField name="period_type" type="string" />
    <ResponseField name="has_next" type="boolean" />
    <ResponseField name="has_prev" type="boolean" />
  </Expandable>
</ResponseField>
