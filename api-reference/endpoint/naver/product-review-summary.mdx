---
title: "Get Product Review Summary"
api: "GET https://scrapebadger.com/v1/naver/products/{origin_product_no}/review-summary"
description: "Rating summary for a Naver storefront product — average score, review count, star distribution and media/type counts."
---

Fetch the **rating summary** for a storefront product — the average review score, total review count, the star distribution and the media/type breakdowns, without pulling the individual reviews.

**Credits:** 5

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Path Parameters

<ParamField path="origin_product_no" type="string" required>
  The product's origin product number.
</ParamField>

## Query Parameters

<ParamField query="leaf_category_id" type="string">
  Leaf category id for the product. Optional — improves summary resolution when known.
</ParamField>

## Response

<ResponseField name="origin_product_no" type="string" />
<ResponseField name="leaf_category_id" type="string" />
<ResponseField name="review_count" type="integer" />
<ResponseField name="average_review_score" type="number" />

## Example

<CodeGroup>

```bash cURL
curl "https://scrapebadger.com/v1/naver/products/5123456789/review-summary" \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const res = await fetch(
  "https://scrapebadger.com/v1/naver/products/5123456789/review-summary",
  { headers: { "X-API-Key": process.env.SCRAPEBADGER_API_KEY } },
);
const data = await res.json();
```

```python Python
import requests

res = requests.get(
    "https://scrapebadger.com/v1/naver/products/5123456789/review-summary",
    headers={"X-API-Key": "YOUR_API_KEY"},
)
data = res.json()
```
