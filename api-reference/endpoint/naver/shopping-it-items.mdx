---
title: "Shopping IT Items"
api: "GET https://scrapebadger.com/v1/naver/shopping/it-items"
description: "Curated Naver Shopping “IT item” editorial cards — themed card lists each carrying a product set."
---

Fetch Naver Shopping's **“IT item” editorial cards** — themed, curated card lists (e.g. trend and best-of round-ups). Each card carries its metadata and an embedded product set.

**Credits:** 5

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Response

<ResponseField name="result_count" type="integer">Cards returned.</ResponseField>
<ResponseField name="cards" type="Card[]">
  Editorial cards.

  <Expandable title="Card">
    <ResponseField name="card_id" type="string" />
    <ResponseField name="card_seq" type="integer" />
    <ResponseField name="card" type="object">
      Card metadata.

      <Expandable title="card">
        <ResponseField name="gender" type="string" />
        <ResponseField name="aggregate_type" type="string" />
        <ResponseField name="text" type="string" />
        <ResponseField name="title" type="string" />
        <ResponseField name="title_best" type="string" />
        <ResponseField name="exposure_rank" type="integer" />
        <ResponseField name="exposure_type" type="string" />
        <ResponseField name="img_url" type="string" />
        <ResponseField name="active_start_ymd" type="string" />
        <ResponseField name="sync_date" type="string" />
      </Expandable>
    </ResponseField>
    <ResponseField name="products" type="Product[]">Products featured on the card.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="best_cards" type="Card[]">The subset of cards flagged as best-of.</ResponseField>
