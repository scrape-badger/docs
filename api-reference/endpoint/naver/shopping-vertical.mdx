---
title: "Shopping Vertical"
api: "GET https://scrapebadger.com/v1/naver/shopping/verticals/{vertical}"
description: "Curated Naver Shopping products for a named snxbest vertical such as fashiontown, shoppinglive or logistics."
---

Fetch the **curated product list for a named Naver Shopping vertical** — the editorial feeds behind the `fashiontown`, `shoppinglive` and `logistics` sections. Returns a fixed set of 12 curated products.

**Credits:** 5

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Path Parameters

<ParamField path="vertical" type="string" required>
  One of `fashiontown`, `shoppinglive` or `logistics`.
</ParamField>

## Response

<ResponseField name="vertical" type="string">Echo of the requested vertical.</ResponseField>
<ResponseField name="result_count" type="integer">Products returned (12).</ResponseField>
<ResponseField name="products" type="Product[]">
  Curated products — same shape as a [`/shopping/deals`](/api-reference/endpoint/naver/shopping-deals) product.

  <Expandable title="Product">
    <ResponseField name="rank" type="integer" />
    <ResponseField name="nv_mid" type="string" />
    <ResponseField name="title" type="string" />
    <ResponseField name="image_url" type="string" />
    <ResponseField name="link_url" type="string" />
    <ResponseField name="price" type="integer" />
    <ResponseField name="discount_price" type="integer" />
    <ResponseField name="discount_rate" type="integer" />
    <ResponseField name="labels" type="string[]" />
    <ResponseField name="is_ad" type="boolean" />
  </Expandable>
</ResponseField>
