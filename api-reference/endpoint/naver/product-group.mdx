---
title: "Get Product Group"
api: "GET https://scrapebadger.com/v1/naver/products/{origin_product_no}/group"
description: "The storefront variant group of a product — the group id and the member origin product numbers."
---

Resolve the **variant group** a product belongs to. SmartStore sellers group colour/size variants under one group; this returns the group id and the member `originProductNo`s so you can fetch each variant.

**Credits:** 5

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Path Parameters

<ParamField path="origin_product_no" type="string" required>
  The product's origin product number.
</ParamField>

## Response

<ResponseField name="origin_product_no" type="string">Echo of the requested product.</ResponseField>
<ResponseField name="group_id" type="string">The variant group id, or `null` when the product is not grouped.</ResponseField>
<ResponseField name="origin_product_nos" type="string[]">Member origin product numbers.</ResponseField>
<ResponseField name="is_grouped" type="boolean" />
