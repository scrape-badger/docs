---
title: "Shopping Brand Rankings"
api: "GET https://scrapebadger.com/v1/naver/shopping/brand-rank"
description: "Naver Shopping brand ranking — the top 20 brands for a category, age bracket and period."
---

Fetch Naver Shopping's **brand ranking** — the top 20 brands for a category, scoped by age bracket, sort metric and period. Each entry carries the brand's rank, name, logo, storefront URL and movement status.

**Credits:** 5

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Query Parameters

<ParamField query="category_id" type="string" default="A">
  `A` for the overall chart, or an 8-digit brand-ranking category id.
</ParamField>

<ParamField query="age_type" type="string" default="ALL">
  Age bracket, e.g. `ALL`, `MEN_20`, `WOMEN_30`.
</ParamField>

<ParamField query="sort_type" type="string" default="BRAND_POPULAR">
  `BRAND_POPULAR` or `BRAND_ISSUE`.
</ParamField>

<ParamField query="period_type" type="string" default="WEEKLY">
  `WEEKLY` or `MONTHLY`.
</ParamField>

<CodeGroup>

```bash cURL

  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const res = await fetch(

const data = await res.json();
```
