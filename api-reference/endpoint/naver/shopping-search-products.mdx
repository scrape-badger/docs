---
title: "Shopping Product Search"
api: "GET https://scrapebadger.com/v1/naver/shopping/search-products"
description: "Product search across Naver Shopping via the mobile integrated-search finder preview — every preview page in one response."
---

Search products across Naver Shopping using the **mobile integrated-search shopping finder**. One call returns the complete finder preview (all preview pages at once), each product carrying its catalogue id, mall, price, discount, review score and category path.

**Credits:** 5

<Note>
  This is the **finder preview** — one response holds every preview page. Deep full-catalog pagination is served by [`/shopping/search-catalog`](/api-reference/endpoint/naver/shopping-search-catalog).
</Note>

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Query Parameters

<ParamField query="query" type="string" required>
  Search keywords.
</ParamField>

<ParamField query="tab" type="string" default="m_view">
  Finder tab: `m_view` or `m_shop`.
</ParamField>

## Example

<CodeGroup>

```bash cURL
curl "https://scrapebadger.com/v1/naver/shopping/search-products?query=무선+이어폰&tab=m_view" \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const res = await fetch(
  "https://scrapebadger.com/v1/naver/shopping/search-products?" +
    new URLSearchParams({"query": "무선 이어폰", "tab": "m_view"}),
  { headers: { "X-API-Key": process.env.SCRAPEBADGER_API_KEY } },
);
const data = await res.json();
```

```python Python
import requests

res = requests.get(
    "https://scrapebadger.com/v1/naver/shopping/search-products",
    headers={"X-API-Key": "YOUR_API_KEY"},
    params={"query": "무선 이어폰", "tab": "m_view"},
)
data = res.json()
```

## Errors

| Status | Meaning |
| ------ | ------- |

| `502` | Unexpected upstream failure — **not billed**. |
