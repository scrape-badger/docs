---
title: "Get Store Products"
api: "GET https://scrapebadger.com/v1/naver/stores/{store_url}/products"
description: "Paginated product listing for a Naver SmartStore / Brand Store, optionally scoped to a display category."
---

List the **products in a storefront**, optionally scoped to one of its display categories. Each product is the storefront listing card — name, price, discount, stock status, review summary and representative image.

**Credits:** 5

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Path Parameters

<ParamField path="store_url" type="string" required>
  Storefront slug.
</ParamField>

## Query Parameters

<ParamField query="host" type="string" default="smartstore">
  Storefront host: `smartstore` or `brand`.
</ParamField>

<ParamField query="category_id" type="string">
  Scope to a display category id from [`/stores/{store_url}/categories`](/api-reference/endpoint/naver/store-categories).
</ParamField>

<ParamField query="page" type="integer" default="1">
  1-based page.
</ParamField>

<ParamField query="size" type="integer" default="20">
  Products per page.
</ParamField>

<ParamField query="sort" type="string" default="POPULARITY">
  Sort order, e.g. `POPULARITY`.
</ParamField>

<ParamField query="channel_uid" type="string">
  Storefront channel uid. Optional — resolved from the slug when omitted.
</ParamField>

## Example

<CodeGroup>

```bash cURL
curl "https://scrapebadger.com/v1/naver/stores/plusink/products?host=smartstore&page=1&size=20" \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const res = await fetch(
  "https://scrapebadger.com/v1/naver/stores/plusink/products?" +
    new URLSearchParams({"host": "smartstore", "page": "1", "size": "20"}),
  { headers: { "X-API-Key": process.env.SCRAPEBADGER_API_KEY } },
);
const data = await res.json();
```

```python Python
import requests

res = requests.get(
    "https://scrapebadger.com/v1/naver/stores/plusink/products",
    headers={"X-API-Key": "YOUR_API_KEY"},
    params={"host": "smartstore", "page": "1", "size": "20"},
)
data = res.json()
```
