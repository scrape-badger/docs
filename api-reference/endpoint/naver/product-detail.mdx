---
title: "Get Product Detail"
api: "GET https://scrapebadger.com/v1/naver/products/{product_no}"
description: "Full product detail for a Naver storefront product — price, options, delivery, seller, category and review stats."
---

Fetch **full product detail** for a Naver storefront product by its channel product number. Returns the name, price and discount, rating and review count, brand and manufacturer, images, options, delivery, seller and category.

**Credits:** 5

<Note>
  Brand Store products return the full record. For a SmartStore product, pass `store_url` or `channel_uid`; the response may be a partial enrichment, in which case `detail_source` is `smartstore_enrich` and `missing_fields[]` lists the fields that could not be filled.
</Note>

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Path Parameters

<ParamField path="product_no" type="string" required>
  Channel product number (the storefront `/products/{no}` id).
</ParamField>

## Query Parameters

<ParamField query="host" type="string" default="brand">
  `brand` or `smartstore`.
</ParamField>

<ParamField query="store_url" type="string">
  Store slug. Required when `channel_uid` is omitted — resolves the channel and Referer.
</ParamField>

<ParamField query="channel_uid" type="string">
  Opaque storefront channel key. Overrides store-home resolution.
</ParamField>

## Response

<ResponseField name="product_no" type="string" />
<ResponseField name="name" type="string" />
<ResponseField name="price" type="integer" />
<ResponseField name="discount_price" type="integer" />
<ResponseField name="discount_rate" type="integer" />
<ResponseField name="rating" type="number" />
<ResponseField name="review_count" type="integer" />
<ResponseField name="brand" type="string" />
<ResponseField name="manufacturer" type="string" />
<ResponseField name="images" type="string[]" />
<ResponseField name="options" type="object[]">Purchasable option combinations.</ResponseField>
<ResponseField name="delivery" type="object">Delivery terms.</ResponseField>
<ResponseField name="seller" type="object">Seller / channel summary.</ResponseField>
<ResponseField name="category" type="object">Category path.</ResponseField>
<ResponseField name="registered_at" type="string">ISO registration time, when the full-detail schema is obtained.</ResponseField>
<ResponseField name="modified_at" type="string">ISO last-modified time, when the full-detail schema is obtained.</ResponseField>
<ResponseField name="detail_source" type="string">`smartstore_enrich` on a SmartStore partial record; omitted otherwise.</ResponseField>
<ResponseField name="missing_fields" type="string[]">Leaf field paths the partial lane could not fill; omitted otherwise.</ResponseField>

## Example

<CodeGroup>

```bash cURL
curl "https://scrapebadger.com/v1/naver/products/7001234567?host=brand&store_url=nike" \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const res = await fetch(
  "https://scrapebadger.com/v1/naver/products/7001234567?" +
    new URLSearchParams({"host": "brand", "store_url": "nike"}),
  { headers: { "X-API-Key": process.env.SCRAPEBADGER_API_KEY } },
);
const data = await res.json();
```

```python Python
import requests

res = requests.get(
    "https://scrapebadger.com/v1/naver/products/7001234567",
    headers={"X-API-Key": "YOUR_API_KEY"},
    params={"host": "brand", "store_url": "nike"},
)
data = res.json()
```

## Errors

| Status | Meaning |
| ------ | ------- |
| `404` | The requested resource does not exist or has been removed. |
| `422` | Naver served a challenge instead of content — **not billed**. Retry; it succeeds. |
| `502` | Unexpected upstream failure — **not billed**. |
