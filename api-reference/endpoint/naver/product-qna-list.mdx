---
title: "List Product Q&A"
api: "GET https://scrapebadger.com/v1/naver/products/{origin_product_no}/qnas"
description: "Paginated product Q&A / inquiries for a Naver storefront product."
---

List the **product Q&A / inquiries** for a storefront product — shopper questions and the seller's answers, paginated.

**Credits:** 5

<Note>
  Brand Store products are fully supported. SmartStore Q&A requires `channel_uid` and may be unavailable.
</Note>

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Path Parameters

<ParamField path="origin_product_no" type="string" required>
  The product's origin product number.
</ParamField>

## Query Parameters

<ParamField query="store_url" type="string" required>
  Store/brand slug.
</ParamField>

<ParamField query="product_no" type="string" required>
  Channel product number (the storefront `/products/{no}` id).
</ParamField>

<ParamField query="host" type="string" default="smartstore">
  `brand` or `smartstore`.
</ParamField>

<ParamField query="channel_uid" type="string">
  Storefront channel uid; required for `host=smartstore`.
</ParamField>

<ParamField query="page" type="integer" default="1">
  1-based page.
</ParamField>

## Response

<ResponseField name="origin_product_no" type="string" />
<ResponseField name="page" type="integer" />
<ResponseField name="total_count" type="integer">Total Q&A entries, when reported.</ResponseField>
<ResponseField name="qnas" type="Qna[]">
  Q&A entries.

  <Expandable title="Qna">
    <ResponseField name="question" type="string" />
    <ResponseField name="answer" type="string" />
    <ResponseField name="author_masked" type="string" />
    <ResponseField name="created_at" type="string" />
    <ResponseField name="answered_at" type="string" />
  </Expandable>
</ResponseField>

