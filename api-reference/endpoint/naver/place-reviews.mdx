---
title: "Get Place Reviews"
api: "GET https://scrapebadger.com/v1/naver/place/{place_id}/reviews"
description: "Visitor reviews for a Naver Place — rating, body, author, visit count, voted keywords and photos per review."
---

Fetch the visitor review stream for a Naver Place. Each review carries its
rating, body text, author, how many times they have visited, the voted
keywords (Naver's structured "what was good" tags), any photos, and whether the
owner has replied.

**Credits:** 5

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Path Parameters

<ParamField path="place_id" type="string" required>
  Naver Place id, e.g. `1234567890`. Take it from `place_id` on a
  [`/local`](/api-reference/endpoint/naver/local) result.
</ParamField>

## Response

<ResponseField name="place_id" type="string" />
<ResponseField name="review_count" type="integer">Total reviews Naver reports for the place.</ResponseField>
<ResponseField name="rating" type="number">Average visitor rating.</ResponseField>
<ResponseField name="result_count" type="integer">Reviews returned in this response.</ResponseField>
<ResponseField name="reviews" type="Review[]">
  Visitor reviews.

  <Expandable title="Review">
    <ResponseField name="review_id" type="string" />
    <ResponseField name="rating" type="number" />
    <ResponseField name="body" type="string">Review text.</ResponseField>
    <ResponseField name="author" type="string" />
    <ResponseField name="visit_count" type="integer">How many times the author has visited.</ResponseField>
    <ResponseField name="origin_type" type="string">Where the review originated, e.g. a receipt- or booking-verified visit.</ResponseField>
    <ResponseField name="visited" type="string">Raw visit date as displayed by Naver.</ResponseField>
    <ResponseField name="visited_at" type="string">ISO 8601 UTC visit date.</ResponseField>
    <ResponseField name="voted_keywords" type="string[]">Naver's structured "what was good" tags, e.g. `음식이 맛있어요`.</ResponseField>
    <ResponseField name="images" type="string[]">Photo URLs attached to the review.</ResponseField>
    <ResponseField name="has_reply" type="boolean">Whether the owner has replied.</ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>

```bash cURL
curl "https://scrapebadger.com/v1/naver/place/1234567890/reviews" \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const res = await fetch(
  "https://scrapebadger.com/v1/naver/place/1234567890/reviews",
  { headers: { "X-API-Key": process.env.SCRAPEBADGER_API_KEY } },
);
const data = await res.json();
```

```python Python
import requests

res = requests.get(
    "https://scrapebadger.com/v1/naver/place/1234567890/reviews",
    headers={"X-API-Key": "YOUR_API_KEY"},
)
data = res.json()
```
