---
title: "List Live Channel Broadcasts"
api: "GET https://scrapebadger.com/v1/naver/shopping/live/channels/{channel_id}/broadcasts"
description: "Broadcast list for a Naver Shopping Live channel, including upcoming standby schedule cards."
---

List a **Shopping Live channel's broadcasts** — past, live and upcoming — including the STANDBY schedule cards for broadcasts not yet started. Cursor-paginated.

**Credits:** 5

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Path Parameters

<ParamField path="channel_id" type="string" required>
  Shopping Live channel id.
</ParamField>

## Response

<ResponseField name="channel_id" type="string" />
<ResponseField name="count" type="integer" />
<ResponseField name="next" type="string">Cursor for the next page, or `null` at the end.</ResponseField>
<ResponseField name="result_count" type="integer" />
<ResponseField name="broadcasts" type="Broadcast[]">
  Broadcast cards.

  <Expandable title="Broadcast">
    <ResponseField name="id" type="string" />
    <ResponseField name="title" type="string" />
    <ResponseField name="status" type="string">e.g. `ONAIR`, `END`, `STANDBY`.</ResponseField>
    <ResponseField name="expectedStartDate" type="string" />
  </Expandable>
</ResponseField>
