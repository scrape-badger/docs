---
title: "Current filter options"
description: "Get native make, model and vehicle filter taxonomy."
openapi: "GET /v1/autoscout24/filters"
---

**Credits:** 2 per successful request. Failed requests cost zero credits.

Pass `market` and optionally a native `make` slug to retrieve its model options. Filter IDs and labels are native marketplace values; use the documented search enums when calling `/search`.
