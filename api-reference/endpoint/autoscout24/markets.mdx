title: "Supported markets"
description: "List verified AutoScout24 marketplaces, languages and currency."
openapi: "GET /v1/autoscout24/markets"

**Credits:** 0 per successful request. Failed requests cost zero credits.

Returns `markets[]` with code, country name, domain, language and currency. Accepted codes are `de`, `at`, `be`, `es`, `fr`, `it`, `lu`, `nl`.
