---
title: "Get Listing"
api: "GET https://scrapebadger.com/v1/gumtree/listings/{listing_id}"
description: "Full Gumtree listing — description, every attribute (full vehicle spec for cars), images, location, seller profile and similar listings."
---

Fetch one Gumtree listing in full: the description, every category attribute,
all images, postcode and coordinates, the seller's profile and Gumtree's
similar listings. Motors listings carry the full vehicle spec — make, model,
mileage, MPG, CO2, insurance group, previous keepers and the vehicle
history-check flags. Property, jobs, pets and services listings carry their own
attribute sets.

**Credits:** 5

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Path Parameters

<ParamField path="listing_id" type="string" required>
  Gumtree listing id — the number at the end of a `gumtree.com/p/...` URL, e.g.
  `1803293391`. Returned as `id` by
  [`/search`](/api-reference/endpoint/gumtree/search).
</ParamField>

## Example

<CodeGroup>

```bash cURL
curl "https://scrapebadger.com/v1/gumtree/listings/1803293391" \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const res = await fetch("https://scrapebadger.com/v1/gumtree/listings/1803293391", {
  headers: { "X-API-Key": process.env.SCRAPEBADGER_API_KEY },
});
const listing = await res.json();
```

```python Python
import requests

res = requests.get(
    "https://scrapebadger.com/v1/gumtree/listings/1803293391",
    headers={"X-API-Key": "YOUR_API_KEY"},
)
listing = res.json()
```

<Note>
  **Phone numbers are masked.** `seller.phone_masked` is the masked form shown
  on the public listing page (e.g. `0794997XXXX`), or `null` when the seller
  shows none. The full number is never returned.
</Note>

<Tip>
  Vehicle history-check flags arrive as attributes with the value `"true"` —
  `vehicle_not_stolen`, `vehicle_not_writeoff`, `vehicle_not_scrapped`,
  `vehicle_not_exported`, `vehicle_road_worthy` — alongside
  `vehicle_previous_keepers` and `vrn` (the registration) where the seller shows
  it.
</Tip>

## Errors

| Status | Meaning |
| ------ | ------- |
| `404` | Listing does not exist or has been removed. |
| `422` | `listing_id` is not 5–12 digits, or Gumtree temporarily refused the request. **Not billed** — retry the latter shortly. |
