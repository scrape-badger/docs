---
title: "Get Listing"
api: "GET https://scrapebadger.com/v1/gumtree/listings/{listing_id}"
description: "Full Gumtree listing from the UK, Australia or South Africa — description, every attribute (full vehicle spec for cars), images, location, seller profile and similar listings."
---

Fetch one Gumtree listing in full: the description, every category attribute,
all images, location and coordinates, the seller's profile and Gumtree's
similar listings. Motors listings carry the vehicle spec — in the UK make,
model, mileage, MPG, CO2, insurance group, previous keepers and the vehicle
history-check flags; in Australia make, model, variant, odometer, VIN and rego.
Property, jobs, pets and services listings carry their own attribute sets.

**Credits:** 5

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Path Parameters

<ParamField path="listing_id" type="string" required>
  Gumtree listing id from the end of the listing URL, returned as `id` by
  [`/search`](/api-reference/endpoint/gumtree/search):

  - `uk`: ~10 digits, e.g. `1803293391`.
  - `au`: ~10 digits, e.g. `1344981847`.
  - `za`: the listing ref at the end of a `gumtree.co.za/listing/<ref>` URL,
    e.g. `ls26bvmcpnsqmz7l9jz`.
</ParamField>

## Query Parameters

<ParamField query="market" type="string" default="uk">
  `uk` (gumtree.com), `au` (gumtree.com.au) or `za` (gumtree.co.za). Must match
  the site the listing id comes from — a `za` ref with `uk` / `au`, or a
  numeric id with `za`, is a `400`.
</ParamField>

<Note>
  **Phone numbers are masked.** `seller.phone_masked` is the masked form shown
  on the public listing page (e.g. `0794997XXXX` in the UK), or `null` when
  the seller shows none — always `null` in Australia and South Africa, where
  Gumtree puts phone numbers behind a login. The full number is never
  returned.
</Note>

<Tip>
  Vehicle history-check flags arrive as attributes with the value `"true"` —
  `vehicle_not_stolen`, `vehicle_not_writeoff`, `vehicle_not_scrapped`,
  `vehicle_not_exported`, `vehicle_road_worthy` — alongside
  `vehicle_previous_keepers` and `vrn` (the registration) where the seller shows
  it.
</Tip>

## Errors

| Status | Meaning |
| ------ | ------- |
| `400` | The `listing_id` belongs to another market — a `za` ref with `uk` / `au`, or a numeric id with `za`. |
| `404` | Listing does not exist or has been removed. |
| `422` | `listing_id` is not 5–30 lowercase letters and digits, or Gumtree temporarily refused the request. **Not billed** — retry the latter shortly. |
