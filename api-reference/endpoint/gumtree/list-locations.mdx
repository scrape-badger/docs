---
title: "List Locations"
api: "GET https://scrapebadger.com/v1/gumtree/locations"
description: "Browse Gumtree's location tree in the UK, Australia or South Africa: nations, states or provinces down to towns."
---

Browse Gumtree's location tree one level at a time. Each child's `slug` is a
valid `location` for [`/search`](/api-reference/endpoint/gumtree/search) — a
name slug on `uk`, the numeric id on `au` and `za`.

- `uk`: United Kingdom → nations → counties → towns.
- `au`: Australia → states → regions → areas, each with its live ad count.
- `za`: South Africa → provinces → towns.

**Credits:** 1 (`uk`, `za`) · 5 (`au`)

<Note>
  On `au` this call renders a real browser past gumtree.com.au's JavaScript
  challenge, so it costs 5 credits and takes 10–20 seconds.
</Note>

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Query Parameters

<ParamField query="market" type="string" default="uk">
  `uk` (gumtree.com), `au` (gumtree.com.au) or `za` (gumtree.co.za).
</ParamField>

<ParamField query="parent_id" type="integer">
  Location id to list the children of. Omit it for the whole country (`uk`
  root `10000392`, `za` root `201`). Then drill down by `id`, e.g. `10000393`
  for England, `3003435` for the Sydney Region, `3100003` for Gauteng.
</ParamField>

## Response

<ResponseField name="market" type="string">`uk`, `au` or `za`.</ResponseField>
<ResponseField name="id" type="integer">The parent location id.</ResponseField>
<ResponseField name="name" type="string">e.g. `England`.</ResponseField>
<ResponseField name="slug" type="string">e.g. `england`.</ResponseField>
<ResponseField name="result_count" type="integer">Number of children.</ResponseField>
<ResponseField name="children" type="TreeNode[]">
  Child locations.

  <Expandable title="TreeNode">
    <ResponseField name="id" type="integer">Pass as `parent_id` to go one level deeper.</ResponseField>
    <ResponseField name="name" type="string" />
    <ResponseField name="slug" type="string">The `/search` `location` value (the id itself on `au` / `za`).</ResponseField>
    <ResponseField name="has_children" type="boolean" />
  </Expandable>
</ResponseField>

## Example

<CodeGroup>

```bash cURL
curl "https://scrapebadger.com/v1/gumtree/locations?parent_id=10000393" \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const res = await fetch(
  "https://scrapebadger.com/v1/gumtree/locations?" +
    new URLSearchParams({ parent_id: "10000393" }),
  { headers: { "X-API-Key": process.env.SCRAPEBADGER_API_KEY } },
);
const { children } = await res.json();
```

```python Python
import requests

res = requests.get(
    "https://scrapebadger.com/v1/gumtree/locations",
    headers={"X-API-Key": "YOUR_API_KEY"},
    params={"parent_id": 10000393},
)
children = res.json()["children"]
```

## Errors

| Status | Meaning |
| ------ | ------- |
| `404` | `parent_id` is not a location of this market (`au`, `za`). |
| `422` | Gumtree temporarily refused the request — **not billed**. Retry shortly. |
