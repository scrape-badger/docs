---
title: "List Locations"
api: "GET https://scrapebadger.com/v1/gumtree/locations"
description: "Browse Gumtree's location tree in the UK, Australia or South Africa: nations, states or provinces down to towns."
---

Browse Gumtree's location tree one level at a time. On `uk` and `au` each
child's `slug` is a valid `location` for
[`/search`](/api-reference/endpoint/gumtree/search) — a name slug on `uk`, the
numeric id on `au`. On `za` pass the child's `id`, a ref such as `dkp8y`
(Gauteng).

- `uk`: United Kingdom → nations → counties → towns.
- `au`: Australia → states → regions → areas, each with its live ad count.
- `za`: South Africa → provinces → towns and suburbs.

**Credits:** 1

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Query Parameters

<ParamField query="market" type="string" default="uk">
  `uk` (gumtree.com), `au` (gumtree.com.au) or `za` (gumtree.co.za).
</ParamField>

<ParamField query="parent_id" type="string">
  Location id (`uk`, `au`: a number) or ref (`za`) to list the children of.
  Omit it for the whole country (`uk` root `10000392`, `za` root `gsptp`). Then
  drill down by `id`, e.g. `10000393` for England, `3003435` for the Sydney
  Region, `dkp8y` for Gauteng.
</ParamField>

## Response

<ResponseField name="market" type="string">`uk`, `au` or `za`.</ResponseField>
<ResponseField name="id" type="integer | string">The parent location id — a ref string on `za`.</ResponseField>
<ResponseField name="name" type="string">e.g. `England`.</ResponseField>
<ResponseField name="slug" type="string">e.g. `england`.</ResponseField>
<ResponseField name="result_count" type="integer">Number of children.</ResponseField>
<ResponseField name="children" type="TreeNode[]">
  Child locations.

  <Expandable title="TreeNode">
    <ResponseField name="id" type="integer | string">Pass as `parent_id` to go one level deeper. On `za` (a ref like `dkp8y`) it is also the `/search` `location` value.</ResponseField>
    <ResponseField name="name" type="string" />
    <ResponseField name="slug" type="string">The `/search` `location` value on `uk` (the id itself on `au`). `null` on `za` — search with the `id`.</ResponseField>
    <ResponseField name="has_children" type="boolean" />
  </Expandable>
</ResponseField>

## Example

<CodeGroup>

```bash cURL
curl "https://scrapebadger.com/v1/gumtree/locations?parent_id=10000393" \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const res = await fetch(
  "https://scrapebadger.com/v1/gumtree/locations?" +
    new URLSearchParams({ parent_id: "10000393" }),
  { headers: { "X-API-Key": process.env.SCRAPEBADGER_API_KEY } },
);
const { children } = await res.json();
```

```python Python
import requests

res = requests.get(
    "https://scrapebadger.com/v1/gumtree/locations",
    headers={"X-API-Key": "YOUR_API_KEY"},
    params={"parent_id": 10000393},
)
children = res.json()["children"]
```

## Errors

| Status | Meaning |
| ------ | ------- |
| `400` | `parent_id` is not a number (`uk`, `au`) or not a ref (`za` — including the old numeric ids). |
| `404` | `parent_id` is not a location of this market (`au`, `za`). |
| `422` | Gumtree temporarily refused the request — **not billed**. Retry shortly. |
