---
title: "Get Seller Listings"
api: "GET https://scrapebadger.com/v1/gumtree/listings/{listing_id}/seller-listings"
description: "Every live listing by the seller of a Gumtree listing, in the UK, Australia or South Africa."
---

List every live ad posted by the seller of `listing_id`. Gumtree keys a
seller's ad list by one of their ads, so **any listing id of theirs works** —
there is no separate seller id to look up. On `au` and `za` the seller is
looked up from the listing first.

**Credits:** 5

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Path Parameters

<ParamField path="listing_id" type="string" required>
  Any Gumtree listing id by the seller, e.g. `1803293391` (`uk`), `1339574407`
  (`au`) or the 26-digit `10013681289561010209976109` (`za`).
</ParamField>

## Query Parameters

<ParamField query="market" type="string" default="uk">
  `uk` (gumtree.com), `au` (gumtree.com.au) or `za` (gumtree.co.za). Must match
  the site the listing id comes from.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Result page, `1`–`50`.
</ParamField>

## Response

<ResponseField name="market" type="string">`uk`, `au` or `za`.</ResponseField>
<ResponseField name="listing_id" type="string">Echo of the listing id the lookup started from.</ResponseField>
<ResponseField name="seller_name" type="string">The seller's display name.</ResponseField>
<ResponseField name="total_results" type="integer">
  Live listings by this seller (`uk`, `au`). `null` on `za`, where the site gives no total — use `has_next`.
</ResponseField>
<ResponseField name="page" type="integer">The page returned.</ResponseField>
<ResponseField name="total_pages" type="integer">`null` on `za`.</ResponseField>
<ResponseField name="has_next" type="boolean">`za`: whether another page follows. `null` elsewhere.</ResponseField>
<ResponseField name="result_count" type="integer">Listings on this page.</ResponseField>
<ResponseField name="listings" type="ListingSummary[]">
  The seller's listings, in the same shape as
  [`/search`](/api-reference/endpoint/gumtree/search#response) listings.
</ResponseField>

## Errors

| Status | Meaning |
| ------ | ------- |
| `400` | The `listing_id` belongs to another market — a 26-digit id with `uk` / `au`, or a short id with `za`. |
| `404` | Listing does not exist or has been removed. |
| `422` | `listing_id` is not 5–30 digits, or Gumtree temporarily refused the request. **Not billed** — retry the latter shortly. |
