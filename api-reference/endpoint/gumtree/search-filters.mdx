---
title: "Get Search Filters"
api: "GET https://scrapebadger.com/v1/gumtree/search/filters"
description: "The filters, sort orders and radius options Gumtree offers for a category, each value with its live result count."
---

List every filter Gumtree offers for a category — make, model, fuel type,
mileage range, bedrooms, job type and so on — with a **live result count** per
value, plus the available sort orders and search radii. Feed a filter's `key`
and an option's `value` straight back into
[`/search`](/api-reference/endpoint/gumtree/search) as `filters=key:value`.
Filter keys are each site's own, so always ask with the `market` you will
search.

**Credits:** 5

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Query Parameters

<ParamField query="market" type="string" default="uk">
  `uk` (gumtree.com), `au` (gumtree.com.au) or `za` (gumtree.co.za).
</ParamField>

<ParamField query="category" type="string" default="all">
  `uk`: category slug, e.g. `cars`, `property-to-rent`, `jobs`. `au` / `za`:
  numeric category id, e.g. `18320` (AU cars) or `9077` (ZA cars). Filters are
  category-specific, so pass the category you intend to search.
</ParamField>

<ParamField query="location" type="string">
  `uk`: location slug, town name or UK postcode. `au` / `za`: numeric location
  id. Scopes the counts. Omit for the whole country.
</ParamField>

<ParamField query="query" type="string">
  Optional keywords to scope the counts.
</ParamField>

<ParamField query="filters" type="string">
  `za` only: filters already applied, as `key:value` pairs. gumtree.co.za
  offers dependent filters only once their parent is set — e.g. `ma:toyota`
  makes the `mo` (model) filter appear with Toyota's models (`hilux`,
  `corolla` …).
</ParamField>

## Response

<ResponseField name="market" type="string">`uk`, `au` or `za`.</ResponseField>
<ResponseField name="category" type="string">Category slug (`uk`) or id (`au`, `za`).</ResponseField>
<ResponseField name="category_name" type="string">e.g. `Cars`.</ResponseField>
<ResponseField name="total_results" type="integer">Matching listings before any filter.</ResponseField>
<ResponseField name="filters" type="SearchFilter[]">
  Filters for the category.

  <Expandable title="SearchFilter">
    <ResponseField name="key" type="string">Filter key for `filters=key:value`, e.g. `vehicle_make`.</ResponseField>
    <ResponseField name="label" type="string">e.g. `Make`.</ResponseField>
    <ResponseField name="type" type="string">`enum`, `multiple_selection`, `enum_range`, `range`, `range_freeform` or `boolean`.</ResponseField>
    <ResponseField name="min_key" type="string">Range filters: the lower-bound key when Gumtree names it explicitly (e.g. `min_price`). Otherwise it is `min_` + `key`.</ResponseField>
    <ResponseField name="max_key" type="string">Range filters: the upper-bound key, likewise `max_` + `key` when null.</ResponseField>
    <ResponseField name="options" type="FilterOption[]">`label`, `value`, `count` — `value` is what `/search` takes. Empty for range filters.</ResponseField>
    <ResponseField name="min_options" type="FilterOption[]">Range filters: the lower bounds Gumtree offers.</ResponseField>
    <ResponseField name="max_options" type="FilterOption[]">Range filters: the upper bounds Gumtree offers.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="sort_options" type="SortOption[]">
  Sort orders Gumtree offers for the category — `value`, `label`.
</ResponseField>
<ResponseField name="distance_options" type="number[]">Search radius values in miles (`uk`). Empty for `au` (any km value up to `1000` is accepted) and `za` (no radius search).</ResponseField>
<ResponseField name="category_facets" type="CategoryFacet[]">Sub-categories with counts — `id`, `name`, `slug`, `count`.</ResponseField>

## Example

<CodeGroup>

```bash cURL
curl "https://scrapebadger.com/v1/gumtree/search/filters?category=cars" \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const res = await fetch(
  "https://scrapebadger.com/v1/gumtree/search/filters?" +
    new URLSearchParams({ category: "cars" }),
  { headers: { "X-API-Key": process.env.SCRAPEBADGER_API_KEY } },
);
const { filters } = await res.json();
```

```python Python
import requests

res = requests.get(
    "https://scrapebadger.com/v1/gumtree/search/filters",
    headers={"X-API-Key": "YOUR_API_KEY"},
    params={"category": "cars"},
)
filters = res.json()["filters"]
```

### Using a filter in `/search`

| Filter `type` | Pass to `/search` as |
| ------------- | -------------------- |
| `enum`, `multiple_selection` | `filters=vehicle_make:bmw` — repeat the key for several values: `vehicle_make:bmw,vehicle_make:audi` |
| `enum_range`, `range` | `filters=min_vehicle_mileage:10000,max_vehicle_mileage:50000` (`min_` / `max_` + `key`, or the explicit `min_key` / `max_key`) |

`price`, `seller_type`, `photos_filter` and `urgent_filter` also appear in this
list for `uk`; on `/search` use the dedicated `min_price` / `max_price`,
`seller_type`, `with_photos` and `urgent_only` parameters for them.

### South Africa

With a make already applied, the model filter (`mo`) lists that make's models
(Toyota cars in Gauteng):

```bash
curl "https://scrapebadger.com/v1/gumtree/search/filters?market=za&category=9077&location=3100003&filters=ma:toyota" \
  -H "X-API-Key: YOUR_API_KEY"
```

### Australia

Australian keys are namespaced by category, e.g. for cars (`18320`):
`cars.carmake_s` (make), `cars.carbodytype_s`, `cars.caryear_i` (a `range` —
`min_cars.caryear_i` / `max_cars.caryear_i`), `cars.fueltype_s`,
`cars.cartransmission_s`, `cars.forsaleby_s` (private or dealer) and
`priceType` (`FIXED`, `NEGOTIABLE` …).

```bash
curl "https://scrapebadger.com/v1/gumtree/search/filters?market=au&category=18320" \
  -H "X-API-Key: YOUR_API_KEY"
```

<Tip>
  Use this endpoint to size a search before paging it: the per-value counts
  tell you which filters bring a result set under the 50-page ceiling of
  `/search`.
</Tip>

## Errors

| Status | Meaning |
| ------ | ------- |
| `400` | An unknown `category` or `location` id, malformed `filters`, or `filters` with `market=uk`. |
| `422` | Gumtree temporarily refused the request — **not billed**. Retry shortly. |
