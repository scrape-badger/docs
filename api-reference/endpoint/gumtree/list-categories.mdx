---
title: "List Categories"
api: "GET https://scrapebadger.com/v1/gumtree/categories"
description: "Browse Gumtree's category tree in the UK, Australia or South Africa. A node's slug is the category value /search takes."
---

Browse Gumtree's category tree one level at a time. Each child's `slug` is the
value [`/search`](/api-reference/endpoint/gumtree/search) and
[`/search/filters`](/api-reference/endpoint/gumtree/search-filters) take as
`category` — a name slug on `uk` (`cars`), the numeric id on `au` and `za`
(`18320`, `9077`).

**Credits:** 1

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Query Parameters

<ParamField query="market" type="string" default="uk">
  `uk` (gumtree.com), `au` (gumtree.com.au) or `za` (gumtree.co.za).
</ParamField>

<ParamField query="parent_id" type="integer">
  Category id to list the children of. Omit it for the market's root — all
  categories (`uk` root id `1`, `au` and `za` root id `0`; the `au` root has 16
  top-level categories, `za` 17). Then drill down by `id`, e.g. `2551` for UK
  Motors, `9299` for AU Cars & Vehicles, `5` for ZA Automotive Vehicles.
</ParamField>

## Response

<ResponseField name="market" type="string">`uk`, `au` or `za`.</ResponseField>
<ResponseField name="id" type="integer">The parent category id.</ResponseField>
<ResponseField name="name" type="string">e.g. `Motors`.</ResponseField>
<ResponseField name="slug" type="string">e.g. `cars-vans-motorbikes`.</ResponseField>
<ResponseField name="result_count" type="integer">Number of children.</ResponseField>
<ResponseField name="children" type="TreeNode[]">
  Child categories.

  <Expandable title="TreeNode">
    <ResponseField name="id" type="integer">Pass as `parent_id` to go one level deeper.</ResponseField>
    <ResponseField name="name" type="string" />
    <ResponseField name="slug" type="string">The `/search` `category` value (the id itself on `au` / `za`).</ResponseField>
    <ResponseField name="has_children" type="boolean" />
  </Expandable>
</ResponseField>

## Example

<CodeGroup>

```bash cURL
curl "https://scrapebadger.com/v1/gumtree/categories?parent_id=2551" \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const res = await fetch(
  "https://scrapebadger.com/v1/gumtree/categories?" +
    new URLSearchParams({ parent_id: "2551" }),
  { headers: { "X-API-Key": process.env.SCRAPEBADGER_API_KEY } },
);
const { children } = await res.json();
```

```python Python
import requests

res = requests.get(
    "https://scrapebadger.com/v1/gumtree/categories",
    headers={"X-API-Key": "YOUR_API_KEY"},
    params={"parent_id": 2551},
)
children = res.json()["children"]
```

```bash
  -H "X-API-Key: YOUR_API_KEY"
```

On `au`, `parent_id=9299` (Cars & Vehicles) lists `18320` (Cars, Vans & Utes)
among its children.

## Errors

| Status | Meaning |
| ------ | ------- |
| `404` | `parent_id` is not a category of this market (`au`, `za`). |
| `422` | Gumtree temporarily refused the request — **not billed**. Retry shortly. |
