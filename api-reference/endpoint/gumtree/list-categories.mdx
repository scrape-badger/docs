---
title: "List Categories"
api: "GET https://scrapebadger.com/v1/gumtree/categories"
description: "Browse Gumtree's category tree in the UK, Australia or South Africa. A node's slug is the category value /search takes."
---

Browse Gumtree's category tree one level at a time. On `uk` and `au` each
child's `slug` is the value [`/search`](/api-reference/endpoint/gumtree/search)
and [`/search/filters`](/api-reference/endpoint/gumtree/search-filters) take as
`category` — a name slug on `uk` (`cars`), the numeric id on `au` (`18320`).
On `za` pass the child's `id`, a ref such as `p6dnh` (Cars & Bakkies).

**Credits:** 1

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Query Parameters

<ParamField query="market" type="string" default="uk">
  `uk` (gumtree.com), `au` (gumtree.com.au) or `za` (gumtree.co.za).
</ParamField>

<ParamField query="parent_id" type="string">
  Category id (`uk`, `au`: a number) or ref (`za`) to list the children of.
  Omit it for the market's root — all categories (`uk` root id `1`, `au` root
  id `0` with 16 top-level categories, `za` root ref `kyzkk` with 17). Then
  drill down by `id`, e.g. `2551` for UK Motors, `9299` for AU Cars &
  Vehicles, `l4dq6` for ZA Vehicles.
</ParamField>

## Response

<ResponseField name="market" type="string">`uk`, `au` or `za`.</ResponseField>
<ResponseField name="id" type="integer | string">The parent category id — a ref string on `za`.</ResponseField>
<ResponseField name="name" type="string">e.g. `Motors`.</ResponseField>
<ResponseField name="slug" type="string">e.g. `cars-vans-motorbikes`.</ResponseField>
<ResponseField name="result_count" type="integer">Number of children.</ResponseField>
<ResponseField name="children" type="TreeNode[]">
  Child categories.

  <Expandable title="TreeNode">
    <ResponseField name="id" type="integer | string">Pass as `parent_id` to go one level deeper. On `za` (a ref like `p6dnh`) it is also the `/search` `category` value.</ResponseField>
    <ResponseField name="name" type="string" />
    <ResponseField name="slug" type="string">The `/search` `category` value on `uk` (the id itself on `au`). On `za`, the site's URL segment (e.g. `cars-bakkies`) — search with the `id` instead.</ResponseField>
    <ResponseField name="has_children" type="boolean" />
  </Expandable>
</ResponseField>

## Example

<CodeGroup>

```bash cURL
curl "https://scrapebadger.com/v1/gumtree/categories?parent_id=2551" \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const res = await fetch(
  "https://scrapebadger.com/v1/gumtree/categories?" +
    new URLSearchParams({ parent_id: "2551" }),
  { headers: { "X-API-Key": process.env.SCRAPEBADGER_API_KEY } },
);
const { children } = await res.json();
```

```python Python
import requests

res = requests.get(
    "https://scrapebadger.com/v1/gumtree/categories",
    headers={"X-API-Key": "YOUR_API_KEY"},
    params={"parent_id": 2551},
)
children = res.json()["children"]
```

### South Africa

```bash
curl "https://scrapebadger.com/v1/gumtree/categories?market=za&parent_id=l4dq6" \
  -H "X-API-Key: YOUR_API_KEY"
```

```json Response (abridged)
{
  "market": "za",
  "id": "l4dq6",
  "name": "Vehicles",
  "slug": "vehicles",
  "result_count": 8,
  "children": [
    { "id": "c07q9", "name": "Auto Parts & Accessories", "slug": "auto-parts-accessories", "has_children": true },
    { "id": "p6dnh", "name": "Cars & Bakkies", "slug": "cars-bakkies", "has_children": false },
    { "id": "b8stt", "name": "Motorcycles & Scooters", "slug": "motorcycles-scooters", "has_children": false }
  ]
}
```

Pass `p6dnh` as `category` to `/search?market=za` — the `slug` (`cars-bakkies`)
is the site's URL segment, not the value `/search` takes.

On `au`, `parent_id=9299` (Cars & Vehicles) lists `18320` (Cars, Vans & Utes)
among its children.

## Errors

| Status | Meaning |
| ------ | ------- |
| `400` | `parent_id` is not a number (`uk`, `au`) or not a ref (`za` — including the old numeric ids). |
| `404` | `parent_id` is not a category of this market (`au`, `za`). |
| `422` | Gumtree temporarily refused the request — **not billed**. Retry shortly. |
