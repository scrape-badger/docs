---
title: "Search Listings"
api: "GET https://scrapebadger.com/v1/gumtree/search"
description: "Search gumtree.com classified ads by keyword, category, town or UK postcode radius, price band, seller type and category-specific filters."
---

Search `gumtree.com` listings across every vertical — For Sale, Motors, Property,
Jobs, Services, Pets and Community. Returns ~25–30 listings per page, up to 50
pages.

**Credits:** 5

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Query Parameters

<ParamField query="query" type="string">
  Search keywords, e.g. `mountain bike`. Optional — omit it to browse a whole
  category.
</ParamField>

<ParamField query="category" type="string" default="all">
  Category slug, e.g. `cars`, `for-sale`, `property-to-rent`, `jobs`, `pets`,
  `bicycles`. Browse every slug with
  [`/categories`](/api-reference/endpoint/gumtree/list-categories).
</ParamField>

<ParamField query="location" type="string" default="uk">
  Location slug (`london`, `manchester`), town name or full UK postcode
  (`SW1A 1AA`). `uk` searches nationwide. Resolve a place with
  [`/locations/autocomplete`](/api-reference/endpoint/gumtree/location-autocomplete).
</ParamField>

<ParamField query="distance" type="number">
  Radius in miles around `location`, greater than `0` and up to `1000`.
</ParamField>

<ParamField query="min_price" type="integer">
  Minimum price in GBP. Needs a `category` other than `all`.
</ParamField>

<ParamField query="max_price" type="integer">
  Maximum price in GBP. Needs a `category` other than `all`.
</ParamField>

<ParamField query="sort" type="string" default="relevance">
  Result ordering. One of `relevance`, `date`, `price_asc`, `price_desc`,
  `distance`.
</ParamField>

<ParamField query="seller_type" type="string">
  `private` or `trade`. `trade` covers dealers, letting agents and recruiters.
</ParamField>

<ParamField query="urgent_only" type="boolean" default="false">
  Only ads the seller marked urgent.
</ParamField>

<ParamField query="with_photos" type="boolean" default="false">
  Only ads with photos.
</ParamField>

<ParamField query="filters" type="string">
  Category-specific filters as comma-separated `key:value` pairs, e.g.
  `vehicle_make:bmw,vehicle_fuel_type:petrol,min_vehicle_mileage:10000`. Repeat
  a key to select several values (`vehicle_make:bmw,vehicle_make:audi`).
  Discover the keys and values for a category with
  [`/search/filters`](/api-reference/endpoint/gumtree/search-filters).
</ParamField>

<ParamField query="page" type="integer" default="1">
  Result page, `1`–`50`.
</ParamField>

import requests

res = requests.get(

)

## Search behaviour

<Note>
  **Price filters need a category.** `min_price` / `max_price` have no effect
  when `category` is `all` — pick a category (`for-sale`, `cars`, `bicycles` …)
  to filter by price.
</Note>

<Note>
  Gumtree pins up to **5 paid featured ads** (`is_featured: true`) above the
  chosen sort order. Skip them if you need a strict date or price ordering.
</Note>

<Warning>
  A result set holds at most **50 pages** (~1,500 listings), whatever
  `total_results` reports. To collect more, narrow the search — by
  sub-category (`category_facets`), location and `distance`, price band, or
  [`filters`](/api-reference/endpoint/gumtree/search-filters).
</Warning>

### Postcode radius

Pass a full UK postcode as `location` with a `distance` in miles:

```bash
curl "https://scrapebadger.com/v1/gumtree/search?query=sofa&category=for-sale&location=SW1A%201AA&distance=2" \
  -H "X-API-Key: YOUR_API_KEY"
```

### Category filters

```bash
curl "https://scrapebadger.com/v1/gumtree/search?category=cars&filters=vehicle_make:bmw,vehicle_fuel_type:petrol,min_vehicle_mileage:10000" \
  -H "X-API-Key: YOUR_API_KEY"
```

Range filters (`type: enum_range`) take `min_` / `max_` + the filter key, e.g.
`min_vehicle_mileage:10000,max_vehicle_mileage:50000`. List every key and value
for a category with
[`/search/filters`](/api-reference/endpoint/gumtree/search-filters).

## Errors

| Status | Meaning |
| ------ | ------- |
| `400` | Malformed `filters` value — expected comma-separated `key:value` pairs. |
| `422` | Invalid parameter (e.g. `page` above 50), or Gumtree temporarily refused the request. **Not billed** — retry the latter shortly. |
