---
title: "Search Listings"
api: "GET https://scrapebadger.com/v1/gumtree/search"
description: "Search Gumtree classified ads in the UK, Australia or South Africa by keyword, category, location and radius, price band, seller type and category-specific filters."
---

Search Gumtree listings across every vertical — For Sale, Motors, Property,
Jobs, Services, Pets and Community — on `gumtree.com` (UK), `gumtree.com.au`
(Australia) or `gumtree.co.za` (South Africa). Returns 25 (UK) or 24 (AU)
listings per page plus any pinned featured ads, up to 50 pages, or 20 (ZA) per
page across the first 375 matches.

**Credits:** 5

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Query Parameters

<ParamField query="market" type="string" default="uk">
  Which Gumtree: `uk` (gumtree.com, GBP), `au` (gumtree.com.au, AUD) or `za`
  (gumtree.co.za, ZAR). Separate sites — category, location and listing ids
  from one market mean nothing in another.
</ParamField>

<ParamField query="query" type="string">
  Search keywords, e.g. `mountain bike`. Optional — omit it to browse a whole
  category.
</ParamField>

<ParamField query="category" type="string" default="all">
  - `uk`: category slug, e.g. `cars`, `for-sale`, `property-to-rent`, `jobs`,
    `pets`, `bicycles`.
  - `au`: numeric category id, e.g. `18320` (cars), `18560` (bicycles).
  - `za`: category ref, e.g. `p6dnh` (Cars & Bakkies), `l4dq6` (Vehicles).

  Browse the tree with
  [`/categories`](/api-reference/endpoint/gumtree/list-categories) for the same
  `market`. An unknown id or ref is a `400`.
</ParamField>

<ParamField query="location" type="string">
  Omit to search the whole country.

  - `uk`: location slug (`london`, `manchester`), town name or full UK postcode
    (`SW1A 1AA`).
  - `au`: numeric location id, e.g. `3003435` (Sydney Region).
  - `za`: location ref, e.g. `dkp8y` (Gauteng), `pfw8k` (Cape Town).

  Resolve a place with
  [`/locations/autocomplete`](/api-reference/endpoint/gumtree/location-autocomplete).
  An unknown location is a `400` — the sites would otherwise silently search
  the whole country.
</ParamField>

<ParamField query="distance" type="number">
  Radius around `location`, greater than `0` and up to `1000`: miles (`uk`) or
  km (`au`, needs a `location`). Not supported for `za`.
</ParamField>

<ParamField query="min_price" type="integer">
  Minimum price in the market's currency. `uk`: needs a `category` other than
  `all`.
</ParamField>

<ParamField query="max_price" type="integer">
  Maximum price in the market's currency. `uk`: needs a `category` other than
  `all`.
</ParamField>

<ParamField query="sort" type="string" default="relevance">
  Result ordering. One of `relevance`, `date`, `price_asc`, `price_desc`,
  `distance`. `distance` needs `uk`, or `au` with a `location`.
</ParamField>

<ParamField query="seller_type" type="string">
  `private` or `trade`. `trade` covers dealers, letting agents and recruiters.
  `uk` and `za` only — on `au` pass it as a filter instead (e.g.
  `cars.forsaleby_s:ownr`).
</ParamField>

<ParamField query="urgent_only" type="boolean" default="false">
  `uk` only: only ads the seller marked urgent.
</ParamField>

<ParamField query="with_photos" type="boolean" default="false">
  `uk` only: only ads with photos.
</ParamField>

<ParamField query="filters" type="string">
  Category-specific filters as comma-separated `key:value` pairs. Range filters
  take `min_<key>:<value>` / `max_<key>:<value>`. Keys differ per market —
  discover them, with their values, from
  [`/search/filters`](/api-reference/endpoint/gumtree/search-filters) for the
  same `market` and `category`:

  - `uk`: `vehicle_make:bmw,vehicle_fuel_type:petrol,min_vehicle_mileage:10000`.
    Repeat a key to select several values (`vehicle_make:bmw,vehicle_make:audi`).
  - `au`: `cars.carmake_s:toyota,min_cars.caryear_i:2015,priceType:NEGOTIABLE`.
  - `za`: `make:toyota,model:hilux,fuelType:diesel,max_mileageKm:100000,min_year:2015`
    — on Cars & Bakkies: `make`, `model`, `bodyType`, `driveType`,
    `transmission`, `fuelType`, `colour`, and the ranges `year` and
    `mileageKm`. Values are case-insensitive (`toyota` = `TOYOTA`). One value
    per key. A key gumtree.co.za does not know is a `400`; a value it does not
    know matches nothing.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Result page, `1`–`50` (`za`: results past the 375th are not reachable; such
  a page comes back empty).
</ParamField>

## Search behaviour

<Note>
  **UK price filters need a category.** gumtree.com ignores `min_price` /
  `max_price` when `category` is `all`, so that combination is a `400` — pick a
  category (`for-sale`, `cars`, `bicycles` …) to filter by price.
</Note>

<Note>
  Gumtree pins **paid featured ads** (`is_featured: true`) above the chosen
  sort order — up to 5 in the UK and up to 6 in Australia. Skip them if you
  need a strict date or price ordering.
</Note>

<Warning>
  A result set holds at most **50 pages** (`za`: the first 375 matches, 19
  pages), whatever `total_results` reports. To
  collect more, narrow the search — by sub-category (`category_facets`),
  location and `distance`, price band, or
  [`filters`](/api-reference/endpoint/gumtree/search-filters). A page past the
  end comes back with no listings and is not billed.
</Warning>

### Market support

| Parameter | `uk` | `au` | `za` |
| --------- | ---- | ---- | ---- |
| `category` / `location` | slug / slug or postcode | numeric id | ref (`p6dnh` / `dkp8y`) |
| `distance` | miles | km (needs `location`) | — |
| `seller_type` | ✓ | as a filter | ✓ |
| `urgent_only`, `with_photos` | ✓ | — | — |
| `sort=distance` | ✓ | with `location` | — |
| Listings per page | 25 + featured | 24 + up to 6 featured | 20 (first 375 matches) |

A parameter a market does not support is a `400`, not silently ignored.

### Postcode radius

Pass a full UK postcode as `location` with a `distance` in miles:

```bash
curl "https://scrapebadger.com/v1/gumtree/search?query=sofa&category=for-sale&location=SW1A%201AA&distance=2" \
  -H "X-API-Key: YOUR_API_KEY"
```

### Category filters

```bash
curl "https://scrapebadger.com/v1/gumtree/search?category=cars&filters=vehicle_make:bmw,vehicle_fuel_type:petrol,min_vehicle_mileage:10000" \
  -H "X-API-Key: YOUR_API_KEY"
```

Range filters (`type: enum_range`) take `min_` / `max_` + the filter key, e.g.
`min_vehicle_mileage:10000,max_vehicle_mileage:50000`. List every key and value
for a category with
[`/search/filters`](/api-reference/endpoint/gumtree/search-filters).

## Errors

| Status | Meaning |
| ------ | ------- |
| `400` | Malformed `filters` value; an unknown `category` or `location` id; a parameter the `market` does not support (see the table above); a `za` filter key gumtree.co.za does not know, or an old numeric `za` id; or `min_price` / `max_price` with `category=all` on `uk`. |
| `422` | Invalid parameter (e.g. `page` above 50), or Gumtree blocked the request. **Not billed**. |
| `503` | Gumtree's origin or transport is temporarily unavailable. **Not billed**. Wait for the `Retry-After` interval (currently 60 seconds) before retrying. |
