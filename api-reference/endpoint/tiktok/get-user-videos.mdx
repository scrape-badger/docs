title: "User Videos, Reposts & Connections"
api: "GET https://scrapebadger.com/v1/tiktok/users/{username}/videos"
description: "Account-free public videos, reposts, followers, following and public liked lists, with continuation cursors."
---

Capture a creator's posted videos and reposts, cursor-paginated.

| Endpoint | Returns | Credits |
| -------- | ------- | ------- |
| `GET /v1/tiktok/users/{username}/videos` | user's posted videos | 8 |
| `GET /v1/tiktok/users/{username}/reposts` | videos the user reposted | 8 |
| `GET /v1/tiktok/users/{username}/followers` | public followers | 10 |
| `GET /v1/tiktok/users/{username}/following` | public following | 10 |
| `GET /v1/tiktok/users/{username}/liked` | public liked videos | 10 |

<Tip>
  Pass `pagination.cursor` back unchanged while `has_more` is true. Cursors belong
  to one resource and region and expire after 15 minutes (HTTP 410). Keep the same
  filters; page size may change. HTTP 403 means the requested list is hidden or
  private. No TikTok account is required.
</Tip>

## Authorization

<ParamField header="X-API-Key" type="string" required>
  Your ScrapeBadger API key.
</ParamField>

## Path Parameters

<ParamField path="username" type="string" required>
  The TikTok handle, without the leading `@` (e.g. `charlidamelio`).
</ParamField>

## Query Parameters

<ParamField query="region" type="string" default="US">
  Content region, ISO 3166-1 alpha-2.
</ParamField>

<ParamField query="count" type="integer" default="30">
  Items per page, 1–50.
</ParamField>

<ParamField query="cursor" type="string">
  Opaque continuation cursor from a prior page's `pagination.cursor`. Available on all lists above.
</ParamField>

## Response — `/videos` and `/reposts`

<ResponseField name="videos" type="TikTokVideo[]">
  Each `TikTokVideo` carries `id`, `description` (caption), `create_time_utc` /
  `create_time_at`, `url`, `share_url`, `aweme_type` (0 video, 150 photo
  slideshow), `is_pinned`, `is_slideshow`, `image_urls[]`, a `stats` object
  (`play_count`, `digg_count`, `comment_count`, `share_count`, `collect_count`),
  `video` media metadata (`duration`, `width`, `height`, `cover`, `play_addr`),
  `music`, `hashtags[]`, `mentions[]`, `challenges[]`, and an embedded `author`.
</ResponseField>
<ResponseField name="pagination" type="TikTokCursorPage">
  `has_more`, `cursor` (opaque — pass back as `cursor`), `count` (items in this
  page).
</ResponseField>
<ResponseField name="region" type="string">Echoes the region.</ResponseField>

## Availability

Public connections and public liked lists are supported. A hidden liked list or
private profile returns HTTP 403. A blocked or unverifiable upstream response
returns HTTP 503, rather than an empty success response.

## Example

<CodeGroup>

```bash cURL
curl "https://scrapebadger.com/v1/tiktok/users/charlidamelio/videos?region=US&count=30" \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const res = await fetch(
  "https://scrapebadger.com/v1/tiktok/users/charlidamelio/videos?" +
    new URLSearchParams({ region: "US", count: "30" }),
  { headers: { "X-API-Key": process.env.SCRAPEBADGER_API_KEY } },
);
const data = await res.json();
```

```python Python
import requests

res = requests.get(
    "https://scrapebadger.com/v1/tiktok/users/charlidamelio/videos",
    headers={"X-API-Key": "YOUR_API_KEY"},
    params={"region": "US", "count": 30},
)
data = res.json()
```
