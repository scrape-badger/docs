Search products.

**Credits:** 10 per successful request. Failed requests and empty result sets are not charged.

## Authentication

<ParamField header="X-API-Key" type="string" required>Your ScrapeBadger API key.</ParamField>

## Parameters

<ParamField query="query" type="string" required>
Query. Minimum length: 1.
</ParamField>

<ParamField query="page" type="integer" default="1">
Page. Minimum: 1. Maximum: 100.
</ParamField>

<ParamField query="sort" type="string" default="best_match">
Sort. Allowed values: `best_match`, `best_selling`, `price_low`, `price_high`, `rating`, `newest`.
</ParamField>

## Example

```bash

  --header 'X-API-Key: YOUR_API_KEY' \
  --data-urlencode 'query=laptop' \
  --data-urlencode 'page=1' \
  --data-urlencode 'sort=best_match'
```
