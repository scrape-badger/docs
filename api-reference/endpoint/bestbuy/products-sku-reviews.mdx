title: "Get product reviews"
api: "GET https://scrapebadger.com/v1/bestbuy/products/{sku}/reviews"
description: "Get product reviews."
---

Get product reviews.

**Credits:** 5 per successful request. Failed requests and empty result sets are not charged.

## Authentication

<ParamField header="X-API-Key" type="string" required>Your ScrapeBadger API key.</ParamField>

## Parameters

<ParamField path="sku" type="string" required>
Sku.
</ParamField>

<ParamField query="page" type="integer" default="1">
Page. Minimum: 1. Maximum: 1000.
</ParamField>

<ParamField query="page_size" type="integer" default="10">
Page size. Minimum: 1. Maximum: 20.
</ParamField>

<ParamField query="sort" type="string" default="MOST_RECENT">
Sort. Allowed values: `MOST_RECENT`, `BEST_REVIEW`, `MOST_HELPFUL`, `OLDEST`, `HIGHEST_RATING`, `LOWEST_RATING`.
</ParamField>

## Example

```bash
curl --get 'https://scrapebadger.com/v1/bestbuy/products/6668412/reviews' \
  --header 'X-API-Key: YOUR_API_KEY' \
  --data-urlencode 'page=1' \
  --data-urlencode 'page_size=10' \
  --data-urlencode 'sort=MOST_RECENT'
```
