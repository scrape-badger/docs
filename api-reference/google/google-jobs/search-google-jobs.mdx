---
title: "Search Google Jobs"
description: "Search public Google Jobs listings or Google Careers openings"
openapi: "GET /v1/google/jobs/search"
---

Use `mode=serp` for public job listings from employers and job boards. The default
`mode=rpc` searches Google's own Careers openings.

In SERP mode, `description` contains the text Google includes for that listing.
When Google supplies a full description, the response includes the text hidden
behind “Show more.” Some markets, including Spanish results, may expose only a
short preview of about 400 characters. Use `apply_links` to open the original
posting when you need the full text. `job_highlights` contains Google's structured
qualifications, responsibilities, and benefits when present; it can be `null`.

There is currently no separate public Google Jobs detail endpoint. Switching to
`mode=rpc` does not expand an aggregator listing; it searches a different source.
Google's own per-job detail response can contain the same truncated preview.
To extract text from the original posting, you can make a separate [Web Scraping
API](/web-scraping/overview) request to an `apply_links` URL. That request
uses Web Scraping pricing and depends on the job board's accessibility.

Each Jobs search costs **20 credits per request**, not per returned job. In SERP
mode, the API attempts to recover missing application links from Google's detail
response for the same job ID, within the existing request deadline. This recovery
adds no customer credit charge. `url` is the Google listing URL; use `apply_links`
or `apply_options[].link` for application destinations. If Google does not supply
a recoverable destination, those arrays can still be empty; the API does not
invent a link or substitute a different listing.

Google Jobs only lists jobs near where it believes the searcher is. In SERP mode the
search is located in the `gl` (or `country`) country, so `q=camarero&gl=es` returns
jobs in Spain without adding "España" to the query. A place in `q` or `location`
still narrows the search, for example `marinero Cádiz`. To pick a different
location, send Google's `uule` value; it replaces the country default.

A successful empty `jobs` array means Google explicitly reported no matching
jobs for that location. Blocked pages and failed fetches return an error. Requests use a bounded
retrieval window of up to 45 seconds; allow at least 60 seconds for your client's
timeout, including network overhead.

```bash
curl --max-time 60 --get 'https://scrapebadger.com/v1/google/jobs/search' \
  -H 'X-API-Key: YOUR_API_KEY' \
  --data-urlencode 'q=marinero empleo España' \
  --data 'mode=serp&gl=es&hl=es'
```
