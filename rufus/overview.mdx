## Overview

The ScrapeBadger **Amazon Rufus API** sends shopping questions to the real **Alexa for Shopping** experience, formerly branded Rufus. It returns the complete answer and any recommended products as structured JSON.

ScrapeBadger manages the authenticated browser sessions, residential exits, and streamed-response reconstruction. You make one REST call.

<Info>
  Endpoints live under `https://scrapebadger.com/v1/rufus/*` and authenticate with the `X-API-Key` header. `/ask` accepts both `GET` and `POST`. Successful responses report credits on the `X-Credits-Used` response header.
</Info>

<Warning>
  Allow up to **100 seconds** for `/ask`. Rufus composes each answer live. Blocked, empty, truncated, and upstream-failed answers are not billed.
</Warning>

## Features

- **Real Rufus answers** — responses come from Amazon's shopping assistant, not a generic model imitating it.
- **Product-aware context** — add an ASIN to ask about a specific product, its reviews, tradeoffs, or alternatives.
- **Complete streamed answers** — JSON Patch events are reduced in order; intermediate fragments are never returned as the final answer.
- **Structured product cards** — ASIN, title, URL, price, rating, rating count, badge, image, and rank when Amazon supplies them.
- **Independent conversations** — every call starts a new conversation so unrelated questions cannot leak context into one another.

<Warning>
  Each request is a fresh, independent question. `thread_id` identifies the exchange for tracing; it is not a multi-turn input. Multi-turn conversations, model selection, and client-side streaming are not supported.
</Warning>

## Quickstart

<CodeGroup>

```bash cURL
curl "https://scrapebadger.com/v1/rufus/ask?asin=B09M7WWTFP&prompt=What%20are%20the%20main%20tradeoffs%20of%20this%20product%3F" \
  -H "X-API-Key: YOUR_API_KEY" \
  --max-time 100
```

```javascript Node.js
const res = await fetch("https://scrapebadger.com/v1/rufus/ask", {
  method: "POST",
  headers: {
    "X-API-Key": process.env.SCRAPEBADGER_API_KEY,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    prompt: "What are the main tradeoffs of this product?",
    asin: "B09M7WWTFP",
  }),
  signal: AbortSignal.timeout(100_000),
});
const data = await res.json();
console.log(data.answer);
console.log(data.products);
```

```python Python
import requests

res = requests.post(
    "https://scrapebadger.com/v1/rufus/ask",
    headers={"X-API-Key": "YOUR_API_KEY"},
    json={
        "prompt": "What are the main tradeoffs of this product?",
        "asin": "B09M7WWTFP",
    },
    timeout=100,
)
data = res.json()
print(data["answer"])
print(data["products"])
```
