# Web Scraping API

Scrape any public webpage and get back clean HTML, Markdown, or plain text. The API handles anti-bot protection, JavaScript rendering, and proxy rotation automatically.

## How It Works

1. **Send a URL** to the `/v1/web/scrape` endpoint
2. **ScrapeBadger picks the best approach** — fast HTTP for simple pages, headless browser for JavaScript-heavy sites
3. **Anti-bot detection runs automatically** — if a block is detected, the request retries with more powerful methods
4. **Get clean content back** in your preferred format (HTML, Markdown, or plain text)

## Scraping Tiers

ScrapeBadger uses a tiered system. When `engine` is set to `"auto"` (the default), the most cost-effective method is tried first and the system escalates automatically if needed.

| Tier | Description | Cost |
|------|-------------|------|
| **HTTP** | Fast HTTP request with Chrome TLS fingerprint — works for most websites | 1 credit |
| **Browser** | Full headless browser with JavaScript rendering — for SPAs and dynamic pages | 5 credits |
| **Premium Browser** | Real browser with advanced fingerprinting — for heavily protected sites | 10 credits |

### Auto-Escalation

When `escalate` is enabled, ScrapeBadger automatically tries more powerful methods if the initial one is blocked:

```
HTTP (1 credit) → Browser (5 credits) → Premium Browser (10 credits)
```

You only pay for the method that succeeds — escalation costs are **not cumulative**.

## Credit Costs

Every request pays an **engine cost plus a `proxy_tier` surcharge**. The engine cost alone is never the total.

| Component | Cost |
|-----------|------|
| HTTP engine — simple pages in `engine: auto` | 1 credit |
| Browser engine — `render_js`, `anti_bot`, `video`, or auto-escalation | 5 credits |
| Proxy tier `simple` (default) | +1 credit |
| Proxy tier `premium` | +8 credits |
| Proxy tier `ultra` | +8 credits |
| AI extraction (`ai_extract: true`) | +10 credits |
| Retries | Free |
| Failed requests | 0 credits |

The anti-bot solver and video recording are not billed on top — they force the browser engine, so they cost the 5-credit engine rate. Common totals:

| Request | Total |
|---------|-------|
| HTTP page, `simple` proxy (cheapest possible scrape) | 2 credits |
| Browser render, `simple` proxy | 6 credits |
| HTTP page, `premium` proxy | 9 credits |
| Browser render, `premium` proxy | 13 credits |

<Tip>
  Use the `max_cost` parameter to set a credit budget per request. The request will fail rather than exceed your budget. The exact charge is returned in `credits_used` and the `X-Credits-Used` response header.
</Tip>

## Caching

`/v1/web/detect` caches its result per domain for **5 minutes**. A cached `detect` response is returned with status `200` and costs **0 credits** — handy when you probe the same domain repeatedly. To get a fresh detection within that window, wait for the 5-minute TTL to lapse.

`/v1/web/scrape` does **not** cache page content: every scrape performs a fresh crawl and is billed for the engine that produced the result. There is no stale-content window to work around.

## Unsupported Sites

Some sites with aggressive, account-gated bot detection are **not supported** and may return errors. In particular, walled social platforms such as **Facebook**, **Instagram**, and **LinkedIn** block automated access behind login and are out of scope for `/v1/web/scrape`. For supported social and marketplace data, use the dedicated source APIs (Twitter/X, Reddit, TikTok, YouTube, etc.).

## Quick Example

<CodeGroup>

```bash cURL
curl -X POST "https://scrapebadger.com/v1/web/scrape" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://scrapebadger.com",
    "format": "markdown"
  }'
```

```python Python
import requests

response = requests.post(
    "https://scrapebadger.com/v1/web/scrape",
    headers={"x-api-key": "YOUR_API_KEY"},
    json={
        "url": "https://scrapebadger.com",
        "format": "markdown"
    }
)

data = response.json()
print(data["content"])
```

```javascript JavaScript
const response = await fetch("https://scrapebadger.com/v1/web/scrape", {
  method: "POST",
  headers: {
    "x-api-key": "YOUR_API_KEY",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    url: "https://scrapebadger.com",
    format: "markdown"
  })
});

const data = await response.json();
console.log(data.content);
```

</CodeGroup>
